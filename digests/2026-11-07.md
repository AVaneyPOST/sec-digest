## General high-severity

**Drupal Commerce Core — CVE-2026-118539 active exploitation**
Drupal's security advisory (highly critical) covers a missing-authorization flaw that lets a remote unauthenticated attacker reach restricted order resources via crafted requests. Affected ranges: Commerce Core 0.0.0–2.41 and 3.0.0–3.3.13. Exploitation was confirmed by Drupal around 2026-10-30/31; coverage continued into 2026-11-05/06 (Rescana, Security Affairs, BleepingComputer summaries). Centarro's follow-up reports two confirmed abuse cases and says it has no evidence of wide scripted exploitation yet — which is not the same as "safe to defer". Practitioner actions: patch to 2.42 or 3.3.14 (or later), audit the `commerce_order` and `commerce_payment` tables for price/quantity anomalies in the last 30 days, and rotate any order-webhook or PSP API keys that could have been reached through order manipulation. Related IDs in the same cycle but separate bugs: CVE-2026-118540 (info disclosure, Commerce Core) and CVE-2026-73475 (access bypass in commerce_paypal contrib module).
[source](https://securityaffairs.com/202162/) · [source](https://www.rescana.com/post/drupal-commerce-core-cve-2026-118539-access-bypass-exploited) · [source](https://app.opencve.io/cve/CVE-2026-118539) · Date: 2026-10-30 → 2026-11-06 (ongoing) · [HIGH]

**Cisco Talos "VOLTA / VOLTA-AUTODOXER" infostealer — Windows, AI-stage victim ranking**
Talos published (2026-10-31) its analysis of a Windows infostealer that performs standard credential/token/cookie theft, then — optionally — sends a per-victim profile to a large language model routed through OpenRouter to rank stolen data by resale value. The AI step is optional; without an API key the malware still steals and exfiltrates. Notable TTPs: bypasses Chrome App-Bound Encryption by launching Chrome with `--headless`, writes a debug log to `%APPDATA%\volta_debug.txt`, self-deletes to frustrate forensics, and uses weak reversible encryption on its configuration strings. Detection ideas that survive the self-delete: alert on Chrome launches with `--headless` by non-Chrome parents, hunt for the `volta_debug.txt` path, and application-control the headless flag outside of CI/test accounts. Practitioner takeaway for telcos: AI-stage victim prioritisation is now in the real-world commodity-stealer loop, which changes the "noise" assumption behind bulk-infection triage.
[source](https://securityaffairs.com/202281/) · [source](https://www.unite.ai/cisco-talos-details-volta-infostealers-llm-victim-ranking-stage/) · [source](https://braindetox.kr/en/posts/volta_infostealer_llm_victim_ranking.html) · Date: 2026-10-31 → 2026-11-06 (ongoing) · [HIGH]
