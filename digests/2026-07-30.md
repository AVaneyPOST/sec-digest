- **Node.js 29 Jul security releases — v22.22.2, v24.18.1, v26.5.1 fix 10 CVEs across all active tracks.** The affected surface list is unusually wide: HTTP/2 stack, mutual-TLS trust handling, DNS resolver, compression path, embedded SQLite bindings, and the `--permission` sandbox model. Three of the ten reach high severity. Concrete items called out in the release notes: (a) CVE-2026-58041, `node:sqlite` `StatementSyncIterator` created via `DatabaseSync#createTagStore()` continues to execute a cached prepared statement after it has been reset and rebound with new parameters, because `SQLTagStore` resets cached statements using `sqlite3_reset()` directly and bypasses the iterator-invalidation mechanism introduced for `StatementSync`; (b) CVE-2026-58042, `dns.resolveAny()` aborts the process when a DNS response contains more than 256 A records, remotely triggerable and repeatable → DoS; (c) an incomplete fix for CVE-2026-48934 where HTTPS-Agent TLS session reuse can skip hostname verification across identity policies (mTLS trust-boundary bypass). Update path is the standard `npm install -g n && n <version>` or distro-package track, but note that this is the third release inside the July cycle across the active branches — anything with a `node_modules` runtime footprint needs a fleet sweep now, not next patch window.
