## Worth watching
- **BeyondTrust Remote Support CVE-2026-102764 — ARMORY CASTLE / UNC5221 / WARP PANDA attribution (Mandiant / GTIG, Oct 19 coverage of Oct 15–16 disclosure).** CVSS 4.0 9.3 (CVSS 3.1 9.1 per some sources) authentication bypass + arbitrary file ops on Remote Support appliances. Exploitation observed since 2026-08-29 against at least one SaaS instance and one self-hosted appliance before public disclosure. Post-exploit: privilege escalation to root, custom malware, credential harvest, control-plane modification, lateral movement into downstream systems. All Remote Support versions through 26.2.3 affected; self-hosted customers running 24.3.1–26.2.3 must apply BT26-05-RS. BeyondTrust says SaaS customers patched by Oct 9. CISA KEV-listed 2026-10-16. For a telco offensive-security practitioner: Remote Support appliances are standard tooling inside MSP/MSSP and operator-SOC environments, and this chain is a direct identity-pivot route into downstream telco tenants. Mandiant explicitly warned they expect broader exploitation attempts to follow. [[SOCPrime](https://socprime.com/?p=54734)] [[eSecurity Planet](https://www.esecurityplanet.com/threats/news-beyondtrust-zero-day-china-hackers/)] [[CISA alert](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-urges-patching-critical-vulnerability-beyondtrust-remote-support)] — Severity: **CRITICAL** (CISA KEV).
- **PEERSTITCH on a telecom MSP (Unit 42, disclosed 2026-10-14; KEV-added via CVE-2025-61624 on 2026-10-16).** Memory-resident ARM64 malware on a managed service provider that resells firewall/managed-security services to telcos and others. Initial access via FortiJump (CVE-2024-47575, FortiManager missing-auth, Oct 2024); privilege/persistence via FortiOS auto-script path traversal **CVE-2025-61624** (patched April 2026, now KEV-listed). PEERSTITCH leaves no on-disk binary, no listening port, no outbound-initiated connection — it piggybacks C2 on legitimate `/bin/miglogd` and `/bin/iked` traffic, which defeats most IDS signature triggers. Exposure: credentials and configs for 500+ downstream customer firewalls. Patching does not evict the implant; defenders need memory forensics + credential rotation. [[SC World – CISA Fortinet/BeyondTrust add](https://scworld.com/brief/cisa-adds-fortinet-and-beyondtrust-vulnerabilities-to-exploited-list)] [[CISA alert](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-adds-two-known-exploited-vulnerabilities-catalog)] — Severity: **HIGH** (telecom-adjacent, nation-state-grade tradecraft).
- **Ivanti Connect Secure CVE-2026-104935 (auth-bypass + chained PE for root; CISA KEV-listed, federal deadline Oct 16).** CVSS 8.6. Volexity found it on a fully-patched appliance; previously-unknown actor **UTA0576** chained it with a separate zero-day privilege-escalation flaw to reach root-level command execution. First exploitation reportedly observed by Defused as early as 2026-10-01; disclosure Oct 13. Fixed in 25.1.1.2 / 25.1.3.0 / 25.1.3.1 / 22.8R2.5 (July 25.1.3.0 already shipped the fix on that branch). ~5,500 ICS instances reachable from the internet per one survey — a large pool of initial-access candidates for roaming-provisioning portals and MVNO back-office hosts. [[SOCPrime](https://socprime.com/?p=54507)] [[IT Daily](https://itdaily.com/news/business/ivanti-bug-ics-2026/)] — Severity: **CRITICAL** (CISA KEV).

Vendor says core alone isn't directly exploitable, but at least one contributed module/custom-code exploit path requires no authentication. Patched releases: 11.4.10, 11.3.19, 10.6.19; 12.0.0-alpha1 through 12.0.0-beta1 are affected. End-of-life 11.2.x/10.5.x/9/8.9 do not receive a patch. Red-team-relevant: telco-sector support portals, developer-doc sites and partner self-service portals frequently run on Drupal. [[Pantheon release note](https://docs.pantheon.io/release-notes/2026/10/drupal-core-security-update)] [[NHS Cyber alert cc-4871](https://digital.nhs.uk/cyber-alerts/2026/cc-4871)] [[cyber.gc.ca AV26-492](https://cyber.gc.ca/en/alerts-advisories/drupal-security-advisory-av26-492)] — Severity: **CRITICAL**.
- **PwnEscape (Linux kernel, CVE-2026-99999 — placeholder-looking ID).** Critical guest-to-host escape in Linux IPv4 packet processing on the virtio-net/TAP path (so KVM-backed VMs are the exposed surface; the bug is not in KVM itself). Discovered by Paulos Yibelo (pwn.ai) during Vercel's Sandbox security challenge. Reports: ~32 bytes of host memory leaked per crafted guest packet; chained to RCE on researcher-controlled hosts; CVSS 3.1 9.3; writeup + fix published 2026-10-15. AWS says managed EC2 / Lambda / Fargate are unaffected. No ITW exploitation reported. CVE ID looks like a placeholder — verify against MITRE/NVD before quoting it to customers. For a telco: on-prem KVM-backed OCS/BSS, SBC lab environments and telco-cloud virtualization are the exposed surface.
