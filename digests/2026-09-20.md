## General high-severity

- **SolarWinds Access Rights Manager CVE-2026-28326 — hardcoded static key enables unauth RCE (2026-09-17 disclosure; broad Sept 19 coverage).** ARM stores a hardcoded static key that lets an attacker who can reach the exposed interfaces bypass authentication and run arbitrary commands on the managed host — full takeover, data exfil, persistence. CVSS 8.8. All versions of Access Rights Manager 2026.2 and prior are affected; fixed in ARM 2026.2.1. Discovered and reported by Kai Huang (Armadin). SolarWinds says no exploitation observed. ARM ranks with SolarWinds Serv-U / Orion as a top ransomware-affiliate target class, so pace the patch accordingly. **Telco relevance**: ARM often sits in the same admin tier as ITSM / IAM stacks feeding OSS/BSS role gates — a hardcoded-key RCE there is a fast lateral to identity plane. [SolarWinds Patches ARM Hard-Coded Key Flaw (Hacker News summary at NuclearCoffee mirror)](https://nuclearcoffee.org/solarwinds-patches-arm-hard-coded-key-flaw-enabling-unauthenticated-rce/) · [Mallory story summary](https://mallory.ai/stories/01a0b5b5-7116-7922-92ae-6b305f900bae) · [OpenCVE CVE-2026-28326](https://app.opencve.io/cve/CVE-2026-28326) — 2026-09-19 (broad coverage) — **HIGH**.
- **BragJack — browser-extension hijack of AI browser agents; Chrome CVE-2026-0628 + Edge CVE-2026-55945 (2026-09-19 broader coverage).** Forever Security disclosed BragJack on Sept 16; through Sept 19 BleepingComputer, Dark Reading, CybersecurityNews and others published deep-dives. A malicious extension seizes the trusted message channels used by AI assistants in Chrome, Microsoft Edge, Opera Neon, Comet and Claude in Chrome, giving the attacker control over the whole prompt, its timing and follow-up commands — **without prompt injection or a guardrail bypass**. Demonstrated capabilities: reading local files, screenshotting, exposing profile info, activating camera/microphone, summarising a victim's emails and exfiltrating them. Google assigned CVE-2026-0628 (CVSS 8.8), fixed in Chrome 143.0.7499.192/.193. Microsoft assigned CVE-2026-55945 (medium-severity race), fixed in Edge <150.0.4078.48. Any user of the five browsers with at least one extension installed was in scope. **Telco relevance**: carrier customer-experience teams increasingly pilot AI browser agents against portals (billing, provisioning, self-service); a compromised extension in that path can trivially exfiltrate cross-tenant session data. [BleepingComputer — BragJack](https://www.bleepingcomputer.com/news/security/bragjack-attacks-hijack-ai-browser-agents-through-malicious-extensions/) · [Dark Reading — Turning agentic AI against itself](https://www.darkreading.com/endpoint-security/bragjack-browser-agentic-ai) · [CybersecurityNews — BragJack across 5 browsers](https://cybersecuritynews.com/bragjack-ai-agent-hijacking/) — 2026-09-19 — **HIGH**.
- **"ShieldCrash" PoC — third-in-a-row bypass of Microsoft Defender ShieldBreak patch (Sept 8 drop; Sept 19 review).** Nightmare Eclipse released ShieldCrash hours after Sept Patch Tuesday: an EoP against the Microsoft Malware Protection Engine that claims SYSTEM on fully patched Windows 10/11 and Server, bypassing Microsoft's fix for ShieldBreak (CVE-2026-69414, CVSS 7.8). Read-only per the author (no write access), which caps immediate ransomware value but keeps it a strong staging primitive. Microsoft has not confirmed the bypass. Third bypass in a row on the same Defender component is the story — the underlying primitive isn't yet contained. [The Hacker News — Researcher drops new Defender PoC](https://thehackernews.com/2026/09/researcher-drops-new-microsoft-defender.html) · [BleepingComputer — ShieldCrash grants SYSTEM](https://www.bleepingcomputer.com/news/security/new-microsoft-defender-shieldcrash-zero-day-grants-system-access/) · [Cyderes analysis](https://www.cyderes.com/howler-cell/shieldcrash-microsoft-zero-day) — 2026-09-19 (fresh coverage) — **NOTABLE** (severity elevated to **HIGH** once/if write-capable variant surfaces).
