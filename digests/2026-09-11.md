## Telecom

**MikroTik RouterOS — CVE-2026-67277 (CVSS 8.8) and CVE-2026-86060 (CVSS 9.2) added to CISA KEV, 2026-09-10** — RouterOS runs the CPE / backhaul / edge routing tier for a large share of WISPs, regional ISPs, and tier-3 access networks; anywhere SSH or the bandwidth-test service is reachable from the interconnect or the public internet, this is a telecom problem, not "just an ISP router" problem.
- **CVE-2026-86060** — SSH argument-handling flaw: a username beginning with a prohibited character mutates the RouterOS policy mask, letting a remote unauthenticated attacker escalate to full administrative control via a crafted username. CVSS 9.2.
- **CVE-2026-67277** — RouterOS accepts a "related" btest connection before its primary session finishes authenticating; an unauthenticated client can start an IPv4 UDP test against the bandwidth-test service, leak kernel memory, or crash / reboot the router. CVSS 8.8.
- Chained together (or with CVE-2026-67276, the CVSS 9.2 SSH auth-bypass sibling not KEV'd yet), the exploit gives unauthenticated remote code execution / full admin. CERT Polska has been observing successful in-the-wild attacks from IP 82.192.72.4 since ≥ 2026-09-02, additional probing from 103.102.31.18. IOC: SSH login as username `-2`, or a persistent account named `ops`. MikroTik shipped fixes 2026-09-03 in RouterOS 7.25beta3, 7.24.2, 7.23.4, and 6.49.21.
- Telco action: enumerate SSH-exposed and bandwidth-test-exposed RouterOS across the CPE / access / management estate (public and management VLANs both), patch to fixed builds now, block internet reach to :22 and the btest ports where possible, and hunt for the two IoCs above (SSH user `-2`, account `ops`). Treat any unpatched, internet-reachable RouterOS device as suspect. Sources: [CERT Polska advisory (2026-09)](https://cert.pl/en/posts/2026/09/vulnerabilities-in-mikrotik-routeros-actively-exploited/), [Industrial Cyber summary of CERT Polska warning](https://industrialcyber.co/critical-infrastructure/cert-polska-alerts-that-mikrotik-routeros-vulnerabilities-actively-being-exploited-in-mikrotrick-attack-chain/), [SecurityAffairs — SSH user "-2" IOC](https://securityaffairs.com/198538/security/your-mikrotik-router-may-already-be-compromised-look-for-ssh-user-2.html), [Help Net Security](https://www.helpnetsecurity.com/2026/09/07/mikrotik-routeros-ssh-vulnerabilities-exploited/), [Cybernews — 122,500 RouterOS routers exposed](https://cybernews.com/security/mikrotik-routers-under-active-exploitation/), [CISA alert page (URL retained for readers, blocked from fetch here)](https://www.cisa.gov/news-events/alerts/2026/09/10/cisa-adds-two-known-exploited-vulnerabilities-catalog).
