## Worth watching
- **Ivanti Connect Secure CVE-2026-104935 (CVSS 8.6, auth bypass → RCE).** Zero-day chain exploited in the wild by threat actor UTA0576 (per Volexity). Fixed in 22.8R2.5, 25.1.3.0, 25.1.3.1, 25.1.1.2. CISA added it to KEV on disclosure (Oct 13); federal remediation deadline Oct 16. A third chained flaw (priv-esc to root) reportedly has no fix yet; attacker leaves no web shell, so Integrity Checker Tool may miss it — defenders should run network/memory forensics. [[Rapid7](https://www.rapid7.com/blog/post/etr-ivanti-connect-secure-zero-day-exploited-in-the-wild-cve-2026-104935/)] [[THN](https://thehackernews.com/2026/10/attacker-chains-three-ivanti-connect.html)] — disclosure Oct 13, 2026. Severity: **CRITICAL**.
- **Microsoft Windows Shell CVE-2026-96951 (CVSS 8.8, Mark-of-the-Web bypass).** Confirmed exploited in the wild; patched in the Oct 13 Patch Tuesday (record ~1,411–1,415 fixes depending on source). Delivery is user-opens-file via phishing/download. Watch for IR cases where a malicious file bypassed MOTW on an unpatched host; a public PoC had not surfaced at search time. [[SOC Prime (FR)](https://socprime.com/?p=54491)] — disclosure Oct 13, 2026. Severity: **HIGH**.
- **Microsoft .NET Framework CVE-2026-108398** (publicly disclosed in Oct 13 Patch Tuesday but no observed exploitation yet). Public details raise the odds exploit code appears quickly. [[Guru3D](https://www.guru3d.com/story/microsoft-fixes-record-1413-vulnerabilities-in-october-2026-patch-tuesday/)] — disclosure Oct 13, 2026. Severity: **NOTABLE**.
- **SharePoint on-prem CVEs CVE-2026-32201 / 45659 / 56164** (and later -58644, -50522). Active exploitation chain reported from mid-July; attackers used them for RCE, IIS machine-key theft, and persistence. Not new today, but any SharePoint on-prem fleet that is not fully patched + machine-key rotated remains in scope. [[Tenable](https://www.tenable.com/blog/cve-2026-32201-cve-2026-45659-cve-2026-56164-faq-sharepoint-server-exploitation)] [[CERT-EU 2026-009](https://cert.europa.eu/publications/security-advisories/2026-009/)].
