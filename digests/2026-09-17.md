## Telecom

- **Cisco ISE — CVE-2026-76460 (CVSS 10.0) actively exploited; CISA KEV Sept 16.** Unauthenticated REST-API authentication bypass, discovered during a Cisco TAC case, meaning at least one production ISE was already compromised before disclosure. For a telco offense practitioner ISE is the AAA/NAC nervous system for enterprise-adjacent OT, admin jump networks, and roaming/lawful-intercept management planes — full-admin takeover of ISE cascades to network device credentials, TACACS, and posture policies. Affects ISE 3.1–3.5. [SecurityWeek](https://www.securityweek.com/critical-command-execution-vulnerability-patched-in-cisco-ise/) · [Cisco advisory (ISE RCE)](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-ise-rce-4fverepv) — 2026-09-16 — **CRITICAL**.
- **Cisco ISE — CVE-2026-76423 (CVSS 10.0) + CVE-2026-76424 arbitrary file access → RCE.** Same-day companion advisory; second unauth REST bypass. Pair CVE-2026-76423 with -76424 for pre-auth code execution as root on the ISE node. [Forkast summary](https://forkast.news/the-gatekeeper-is-the-door-cisco-ises-nine-cve-disclosure-and-the-identity-infrastructure-attack-surface/) — 2026-09-16 — **CRITICAL**.
- **Cisco ISE — CVE-2026-20305 / CVE-2026-20306 (CVSS 9.1) command injection.** Authenticated command injection in diagnostic tooling and REST API respectively → root escalation. Useful post-auth pivots after any low-priv creds or lateral session. [DailyCVE](https://dailycve.com/cisco-identity-services-engine-ise-authentication-bypass-cve-2026-76460-critical-dc-sep2026-2407/) — 2026-09-16 — **HIGH**.
- **Cisco Secure Firewall ASA / FTD / FMC — September 2026 hardening (18 CVEs, several root RCE).** SQLi (CVE-2026-20344, CVSS 8.8), privilege escalation, information disclosure. ASA/FTD sit on the enterprise-facing edge of many mobile core estates (SGi/N6 protection, roaming DMZs). Follows the August ASA/FTD VPN-DoS activity Cisco already flagged as under active exploitation. [SecurityOnline](https://securityonline.info/cisco-secure-firewall-vulnerabilities-september-2026/) · [Cisco hardening advisory](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-hardening-asaftdfmc-uvpPROhN) — 2026-09-16 — **HIGH**.
- **Cisco IOS XR — Security Hardening Release Sept 2026 (CVE-2026-20274 → CVE-2026-20280).** Seven CWE-grouped CVEs across every IOS XR train including LNT/XR7. Not known exploited, but IOS XR is the workhorse in operator provider-edge, mobile-backhaul PE, and 5G transport aggregation; ~16 SMUs per release. Patch runbook is non-trivial and reviewers should expect SMU-vs-full-image drift. [Cisco advisory](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-hardening-iosxr-qg64NcM) · [AiCybr writeup](https://aicybr.com/blog/cisco-ios-xr-september-2026-security-hardening) — 2026-09-16 — **HIGH**.
- **Google Pixel modem zero-day — CVE-2026-58704.** Elevation-of-privilege in the cellular modem, low-complexity, no user interaction, exploited in the wild in targeted attacks. Baseband bugs sit under the AP OS and are precisely what an interconnect/lawful-intercept adversary wants for stealthy footholds. Fix ships in Pixel 2026-09-05 patch level. [BleepingComputer](https://www.bleepingcomputer.com/news/security/google-fixes-actively-exploited-android-zero-day-on-pixel-devices/) · [Security Affairs](https://securityaffairs.com/199193/hacking/google-patches-pixel-modem-zero-day-exploited-in-targeted-attacks.html) — 2026-09-16 — **HIGH**.
