Cisco says there is no workaround. Affected trains: all versions prior to 20.9; 20.9.x < 20.9.10.1; 20.12.x < 20.12.8.2; 20.15.x < 20.15.6.1; 20.18.x < 20.18.4.1; 26.1.x < 26.1.2.1; 26.2.x < 26.2.1. Telecom-practitioner relevance: Catalyst SD-WAN Manager (formerly vManage) is a common choice for managed-SD-WAN operators, MVNE / MVNO fleets layering enterprise WAN over mobile backhaul, and carriers running managed enterprise VPN; unauthenticated admin takeover of the control plane yields policy, routing, device-provisioning and credential-exfiltration primitives across every spoke. If any Catalyst SD-WAN Manager instance is reachable from anywhere other than a hardened OOB jump host, bring it inside, patch to the above trains, rotate operator credentials and API tokens, and audit `/dataservice/*` access logs for anomalous URL-encoded path components. Unauthenticated remote path traversal (CWE-22) combined with improper NULL-byte handling (CWE-158) in the management interface allows an attacker to write arbitrary files on the appliance via crafted HTTP(S) requests — the practical outcome is `.so` preload, webshell drop and configuration tampering, all pre-auth, all over the admin plane. **Affected:** FortiMail 8.0.0-8.0.1, 7.6.0-7.6.6, 7.4.0-7.4.8, 7.2.0-7.2.9. **Fixed:** 8.0.2, 7.6.7, 7.4.9 (7.0 branch has no scheduled fix, migrate off 7.0). **Interim workaround** (Fortinet): disable IBE (Identity-Based Encryption) and restrict management-interface access to trusted networks (`trusthost` / dedicated OOB only). **Vendor-published IOCs:** dropped files `/data/lib/liblog.so`, `/data/bin/webconsole`, `/data/bin/mailservice`, `/data/etc/ld.so.preload`; tampered artifacts `/bin/smit`, `/data/etc/httpd.conf`, `/data/migadmin.tar.gz`. Telecom-practitioner relevance: FortiMail is a common choice for carrier email relays, enterprise mail-gateway services sold to business customers, dealer / channel inboxes, NOC help-desk / ticketing-forwarders and MVNO back-office mail; any such appliance exposing its admin plane outside OOB is in scope.
