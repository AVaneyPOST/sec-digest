Unauthenticated remote path traversal (CWE-22) combined with improper NULL-byte handling (CWE-158) in the management interface lets an attacker write arbitrary files to the underlying OS via crafted HTTP(S) requests — practical outcome is `.so` preload, webshell drop and configuration tampering, all pre-auth, all over the admin plane. **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. **Fixed:** 8.0.2, 7.6.7, 7.4.9 (7.2 branch upgrade to 7.4+). **Interim workaround** (Fortinet): disable IBE (Identity-Based Encryption) and restrict management-interface access to trusted networks (`trusthost` / dedicated OOB only). **Vendor-published IOCs:** dropped files `/data/lib/liblog.so`, `/data/bin/webconsole`, `/data/bin/mailservice`, `/data/etc/ld.so.preload`; tampered artifacts `/bin/smit`, `/data/etc/httpd.conf`, `/data/migadmin.tar.gz`.
