## Telecom

- **Fire Ant expands from VMware to Cisco IOS XR routers, TACACS servers and Linux management hosts (Sygnia).** [HIGH] IR firm Sygnia disclosed today that the China-nexus actor it tracks as Fire Ant — best known from 2025 for VMware hypervisor abuse — has moved into carrier-class network infrastructure. Investigation started with an unexplained active GRE tunnel on a Cisco IOS XR router that had no matching running-config or commit history. Custom IOS XR malware: a modified system library that suppresses outgoing syslog messages unless they contain the string `Health` (so operators still see healthy-sounding events); a hook on the router's command-execution path that appends `| exclude` filters to `show` commands to hide the attacker's tunnel from admins; a persistence service that runs the implant only during alternating hours to defeat baseline analysis. New tool BridgeAgent masquerades as a Zabbix monitoring binary and provides tunneling / persistence. Fire Ant also compromises the TACACS servers themselves (so authentication is against attacker-owned infrastructure) and Linux management hosts. For a telco red-team: the tradecraft is directly applicable to signalling-management planes, roaming NOCs and any environment where IOS XR + TACACS + jump-hosts sit on the same trust perimeter — worth adding as a scenario to internal purple-team libraries. [BleepingComputer](https://www.bleepingcomputer.com/news/security/chinese-fire-ant-hackers-turn-cisco-routers-into-spying-platforms/) · [The Hacker News](https://thehackernews.com/2026/08/china-linked-fire-ant-hijacks-cisco.html) · [Sygnia](https://www.sygnia.co/blog/fire-ant-evolves-from-hypervisors-to-trusted-infrastructure/) · [Cybersecurity Dive](https://www.cybersecuritydive.com/news/state-actor-cisco-routers-China-espionage/829181/) · [Security Affairs](https://securityaffairs.com/198183/apt/china-linked-fire-ant-hides-inside-trusted-infrastructure.html) — 2026-08-31

- **TerminalFix — ClickFix variant using Windows Terminal, PNG steganography, custom reverse tunnel.** [HIGH] Compromised sites serve a fake Cloudflare CAPTCHA that copies a PowerShell one-liner into the clipboard and instructs the user to paste it into Windows Terminal (not the Run dialog — Terminal is more tolerant of multi-line scripts, giving the attacker higher payload complexity). The chain then does DLL sideloading via `LockScreenContentServer.exe`, extracts payloads from PNG steganography, runs extensive Active Directory reconnaissance and drops a custom reverse-tunnel implant that gives the operator network-level proxy access into the victim's internal network. Microsoft published on 2026-08-28; The Register and BleepingComputer picked it up in-window today. Detection: alert on `LockScreenContentServer.exe` outside its normal path, restrict interactive PowerShell, and monitor for outbound WebSocket to unknown infrastructure from workstation hosts.
