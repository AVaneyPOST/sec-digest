## General high-severity

- **Gitea CVE-2026-60004 — critical RCE, now on CISA KEV, in-the-wild exploitation confirmed.** CISA added CVE-2026-60004 to KEV on **Aug 25**; first public exploitation write-up (Habr, an incident report by a self-hosted Gitea admin whose instance was compromised into a crypto-mining zombie) landed on **Aug 26**. Root cause: a code-injection path in Gitea's diffpatch endpoint that lets any user with ordinary repository write access plant an executable Git hook and run arbitrary shell commands as the Gitea service account (CVSS 9.8). Patched in **Gitea 1.27.1** on Jul 27 with the formal advisory on Jul 28 — a one-month exploit window that is now closed. FCEB agencies must remediate by **Aug 28**. Practical action: patch, audit `git-hooks/` on every repo for anything you did not put there, and rotate any secret the Gitea service account had access to. — [CISA KEV entry](https://www.cisa.gov/news-events/alerts/2026/08/25/cisa-adds-one-known-exploited-vulnerability-catalog) · [Help Net Security](https://www.helpnetsecurity.com/2026/08/26/gitea-cve-2026-60004-exploited-in-the-wild/) · [The Hacker News](https://thehackernews.com/2026/08/critical-gitea-rce-actively-exploited.html) · [SecurityWeek](https://www.securityweek.com/cisa-warns-of-exploited-gitea-vulnerability/) · [SocPrime](https://socprime.com/blog/cve-2026-60004-critical-gitea-rce-exploited-to-deploy-miner-like-payloads/) · [Security Affairs](https://securityaffairs.com/197854/security/u-s-cisa-adds-gitea-flaw-to-its-known-exploited-vulnerabilities-catalog.html) · Date: **2026-08-25** (KEV addition) / **2026-08-26** (exploitation coverage) · **CRITICAL**
- **NVIDIA NemoClaw CVE-2026-65105 — drive-by AI-agent hijack via DNS rebinding to unauthenticated Ollama.** Oasis Security disclosed a design flaw in NVIDIA's NemoClaw local-AI-agent runtime: it launches Ollama with `OLLAMA_HOST=0.0.0.0:11434`, binding the model API to every network interface with no authentication. A malicious web page uses a standard DNS-rebinding pivot to route API calls from the browser to the local Ollama, then rewrites the model's chat template — the layer that turns every conversation into the text the model sees — so a hidden attacker instruction is injected into **every subsequent conversation**, not just the current one. From a single page visit, an attacker can enumerate installed models, exfiltrate the machine's public key, and persistently poison every agent that shares the Ollama instance. Fixed in **NemoClaw v0.0.35** on macOS and Linux; the Windows/WSL installer at v0.0.34 still ships without a fix and warns instead. If you run NemoClaw on Windows, treat it as vulnerable and firewall port 11434 to localhost yourself. — [The Hacker News](https://thehackernews.com/2026/08/a-malicious-webpage-could-poison-your.html) · [Oasis / Cyera research](https://www.cyera.com/research/nemoclaw-one-website-visit-to-hijack-your-ai-agent) · [SiliconAngle](https://siliconangle.com/2026/08/25/nvidia-nemoclaw-flaw-let-attackers-poison-the-model-behind-a-developers-ai-agent/) · [Hackread](https://hackread.com/nvidia-nemoclaw-flaw-hijack-openclaw-ai-agents/) · [Security Boulevard](https://securityboulevard.com/2026/08/oasis-security-researchers-reveal-security-flaw-in-nemoclaw-ai-agent/) · Date: **2026-08-25** (disclosure) / **2026-08-26** (broader coverage) · **HIGH**
- **AnonyMousKIT PhaaS — AI voice agents used to phish iPhone passcodes and disable Activation Lock (SOCRadar → Aug 26 coverage).** First fully-productised end-to-end funnel for the stolen-iPhone unlock workflow: buyer feeds a phone number and stolen device serial into a credit-metered console; kit drives lures across email (1.5 credits), SMS (priced by sender ID), WhatsApp, recorded call (1 credit), and a VAPI.ai voice-AI agent (2 credits) that speaks to the victim as "Apple Support" and asks them to confirm their 4- or 6-digit passcode "so Apple can hand the phone back." Researchers recovered **200 call records, 55 transcripts, five personas**, ran between Aug 2025 and May 2026; **179 of the 200 targets were Brazilian numbers**; the entire recovered campaign cost operators **$19.24** — roughly ten cents per attempted victim. SOCRadar counts **506 domains** and **168 reseller storefronts** feeding the platform. If you or your users have had a device stolen, the follow-up "Apple Support" call is now an expected part of the operation. — [The Hacker News](https://thehackernews.com/2026/08/fake-apple-support-ai-calls-target.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/anonymouskit-phaas-uses-voice-ai-agents-to-phish-iphone-passcodes/) · [Help Net Security](https://www.helpnetsecurity.com/2026/08/26/anonymouskit-phishing-stolen-iphone/) · [CyberInsider](https://cyberinsider.com/anonymouskit-service-uses-ai-calls-to-unlock-stolen-apple-devices/) · [Cybernews](https://cybernews.com/cybercrime/stolen-iphone-ai-phishing-apple-support-scam-passcodes/) · [SC Media](https://www.scworld.com/brief/anonymouskit-phishing-service-targets-apple-credentials-and-activation-lock) · Date: **2026-08-26** · **HIGH**
