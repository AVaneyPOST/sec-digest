## Telecom

Quiet day on the direct telecom beat. Nothing I can confirm as newly disclosed in the
window on SS7/MAP, Diameter, GTP, SIGTRAN, 5G SBA/N32, SIM/eSIM, IMS/XCAP, GSMA FS.*,
or a named operator breach. Items worth awareness even though they are not strictly
telecom-protocol stories:

- **BeyondTrust Remote Support zero-day — ARMORY CASTLE / UNC5221 campaign.**
  Advisory BT26-05 / **CVE-2026-102764**, CVSS 9.3, improper origin validation
  (CWE-290) in an internal messaging component. BeyondTrust SaaS was patched by
  2026-10-09; self-hosted customers must apply BT26-05-RS on 24.3.1–26.2.3 (older
  releases need an upgrade first). Exploitation observed from 2026-08-29. Mandiant /
  GTIG attribute to **ARMORY CASTLE**, previously tracked as **UNC5221** (also WARP
  PANDA) — the same cluster behind historical Ivanti Connect Secure / Pulse zero-days
  that have hit telco edge estates before. Mandiant guidance: look for unauth privilege
  changes, altered proxy settings, log gaps, and SAWFLY / BARECLAW implants. Relevance
  to a telco offensive-security practitioner: Remote Support appliances sit at the
  support/privileged-access tier and often front OSS/BSS or vendor-managed network
  elements. [BeyondTrust BT26-05](https://www.beyondtrust.com/trust-center/security-advisories/bt26-05),
  [SOCRadar](https://socradar.io/blog/cve-2026-102764-beyondtrust-zero-day/),
  [GBHackers](https://gbhackers.com/beyondtrust-zero-day-exploited). Date: 2026-10-15
  (advisory) / 2026-10-16 (threat-intel reporting). **[CRITICAL]**

## General high-severity

- **Nextcloud Collabora "built-in CODE Server" — CVE-2026-110447.** Unauthenticated
  remote command execution reachable through `proxy.php` in the `richdocumentscode`
  Nextcloud app when the embedded CODE server isn't running (after a restart, upgrade,
  or crash). Fixed in 26.4.303 (released 2026-09-11); vendor advisory 2026-10-14. First
  logged exploitation 2026-09-10, now reported as a webshell wave. Standalone Collabora
  Online servers are not affected. Reported CVSS 9.2 from one secondary source, NVD
  score pending. Fix: upgrade or remove the app and audit `/apps/richdocumentscode/`
  for unexpected PHP files.
  [The Hacker News](https://thehackernews.com/2026/10/hackers-backdoor-nextcloud-servers.html),
  [SecurityOnline](https://securityonline.info/nextcloud-collabora-online-cve-2026-110447-exploited/).
  Date: 2026-10-14 advisory, exploitation reporting 2026-10-15/16. **[CRITICAL]**

- **GreyNoise: proxyjacking of 143 devices across 34 countries.** Attackers are
  installing a bandwidth-sharing client on unpatched edge devices to monetise them as
  residential proxies. Entry vectors are old: **CVE-2024-3272 / CVE-2024-3273**
  (D-Link ShareCenter NAS), **CVE-2021-44228** (Log4Shell on Ubiquiti UniFi Video
  NVR), **CVE-2025-31324** (SAP NetWeaver Visual Composer). Legitimate indicator for
  a telco SOC: unexpected outbound to known proxy-sharing SaaS from engineering NAS or
  video-surveillance hosts.
  [GBHackers](https://gbhackers.com/proxyjacking-campaign/). Date: 2026-10-16. **[HIGH]**

## Worth watching

- **Cisco Secure Email Gateway — CVE-2026-76519 (CVSS 9.8).** Disclosed 2026-10-14,
  path traversal in the AMP File Reputation path giving root-level command execution
  when File Reputation is enabled. Cisco confirms in-the-wild exploitation; CISA added
  it to KEV on 2026-10-14 (outside today's 24 h window but relevant if you're still
  patching). No workaround; upgrade Content Scanner Tools to 25.3.0.5525+.
  [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisco-patches-actively-exploited-secure-email-gateway-zero-day/),
  [Help Net Security](https://www.helpnetsecurity.com/2026/10/15/cve-2026-0322-cve-2026-76519-cve-2026-105133-cve-2026-105134-exploted/).
  Date: 2026-10-14. **[CRITICAL — carryover]**

- **ARMORY CASTLE / UNC5221 TTP continuity.** The same cluster that burned Ivanti CS
  zero-days earlier is now operating against BeyondTrust appliances with log-wiping

  artefacts). No new telco-named victims so far.
