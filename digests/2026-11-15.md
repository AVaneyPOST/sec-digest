**Fireworks AI → Cursor → Uber third-party chain — in-window attribution update** · [HIGH]
In-window on 2026-11-14, Cursor's own post-incident write-up for the 2026-10-29 Marketplace compromise (malicious Claude Code extension v2.1.313, live ~11 hours, ≤5,000 developers installed, payload: SSH backdoor key + reverse tunnel + macOS/Windows persistence) now names the root cause as a stolen Fireworks AI access key used to publish the tampered extension. Hunt / mitigate: rotate every Fireworks AI API key issued before 2026-11-14 regardless of exposure signal; audit outbound traffic from any ML/inference workload that was active in October 2026; check for Claude Code extension v2.1.312 or v2.1.313 on any developer or SRE endpoint (update to Claude Code for VS Code 2.1.314 or later).

**SCKit worm-like toolkit on ScreenConnect-attacked MSPs** · [HIGH]
BleepingComputer in-window 2026-11-14: SCKit is being deployed in the continuing ScreenConnect-exploitation campaign (post-CVE-2026 client file-transfer family, pre-v26.6.5). Design is worm-like and specifically oriented to lateral-move from compromised downstream customer endpoints *back up* to the MSP technician's workstation. Telecom relevance is indirect but not zero: many Tier-2 / Tier-3 operators and most CLECs outsource field-tech dispatch, NOC overflow, and billing-system administration through MSPs; an SCKit foothold at an MSP serving an operator customer is a plausible pivot into operator BSS / OSS or into the operator's own ScreenConnect instance if one exists. Hunt: ScreenConnect client versions pre-26.6.5, unusual outbound ScreenConnect-client traffic from field-tech laptops, signed-installer anomalies on technician workstations.

## Worth watching

- **UnrealIRCd + Check Point DynamicCLI KEV deadlines hit tomorrow 2026-11-16.** If either stays unpatched on any operator perimeter past tomorrow, the operator is on the wrong side of a federal remediation deadline. UnrealIRCd rarely lives on carrier infrastructure, but Check Point Gaia does appear in operator-IT DMZ and some M2M management segments; this is where the triage should go.
- **Fireworks AI blast radius.** The Cursor + Uber pair confirmed in-window are almost certainly the first two of many — any downstream customer of Fireworks AI that used long-lived API keys and hadn't rotated them before 2026-11-14 is a candidate. Watch for a third / fourth named victim before end of weekend, and for Fireworks AI's own post-mortem.
- **SilentAir operator-side disclosures.** Enea named no operators; the half-dozen Asian carriers whose nodes were involved have not confirmed cleanup. First named-operator confirmation (or denial) would reshape the story. Any Mandiant / CrowdStrike / Lookout follow-up tying GTPDoor to Liminal Panda / LightBasin remains the single most actionable telco-hunt artifact pending.
- **SCKit payload class.** If a public sample or Yara signature lands over the weekend it will materially change how fast MSP-serving operators can hunt their field-tech endpoints.
- **Possible Windows CLFS SYSTEM-level public exploit outside Patch Tuesday.** One aggregator in-window referenced a public exploit letting a standard user reach SYSTEM via CLFS, allegedly not fixed in November Patch Tuesday. Treated as unverified until a primary-source advisory or BC / Rapid7 / Microsoft confirmation lands; if real, this is an EDR-disable primitive that threat-actors operating inside a telco IT estate would use.
- **FaceStealer / North Korea meeting-lure campaign.** FBI attribution to DPRK with >$400M theft figure surfaced in-window via aggregator. Not telecom-targeted but telco finance / treasury exposure (for any operator with crypto-settlement or interconnect-balancing stablecoin exposure) is non-zero.
