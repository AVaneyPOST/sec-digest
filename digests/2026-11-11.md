- **CISA KEV added six entries at 2026-11-10 19:03 UTC — two land directly in a telecom practitioner's scope.** Catalog version advanced to **2026.11.10** (`dateReleased` 2026-11-10T19:03:29.8375Z); 1,779 entries (+6). - **Cisco BroadWorks XXE — CVE-2026-20320 — on KEV in-window (deadline 2026-11-24).** Cisco published the advisory (cisco-sa-bworks-xxe-uwUd7CEt) on 2026-08-19 as "no known exploitation"; the KEV addition is the status change. Out-of-band blind XXE in the OCI (Open Client Interface) XML parser lets an unauthenticated remote attacker read configuration data (likely includes deployment secrets and tenant metadata) from BroadWorks releases earlier than **RI.2026.07**. CVSS 7.5; no workarounds; upgrade is the only remediation. Operationally urgent: BroadWorks is the carrier-grade hosted-PBX / UC-as-a-Service backend at a long list of Tier-1/Tier-2 operators worldwide — any public-facing OCI endpoint should be assumed probed.
- **Openwave Webtop Media Transcoder — CVE-2026-111793 — on KEV in-window (deadline 2026-11-24).** JPCERT/CC JVNVU#93403064 and Openwave's own advisory both note the developer has observed exploitation in the wild. The transcoder fails to enforce admin-configured file-type limits — an authenticated user can convert document types outside policy — CVSS 4.3, CWE-669. Fixed in **1.1.22.0** (or current Media Server 2.0). Openwave Messaging powers carrier webmail at a majority of global operators and large enterprise messaging stacks; this is a privilege-respecting file-type bypass, not RCE, but exposure to malicious document conversion inside hosted mailbox pipelines is a stepping stone for broader compromise.
- **Microsoft Patch Tuesday 2026-11 landed with 1,093 CVEs, 63 Critical, one exploited zero-day.** Headline items: **CVE-2026-124194 Outlook spoofing** (NTLMv2 hash exposure, exploited in the wild, CISA KEV, CVSS ~6.5 — unusually low score for a KEV listing); **CVE-2026-119958 Windows LDAP RCE CVSS 9.8** (unauthenticated, domain-controller impact); **CVE-2026-116928 Windows Search RCE CVSS 9.8**; **CVE-2026-119952 Windows Schannel RCE CVSS 8.1 "Exploitation More Likely"**; **CVE-2026-118207 Exchange Server RCE CVSS 8.8**; **CVE-2026-109469 Entra Device Registration EoP CVSS 10.0**; eight critical Hyper-V EoP CVEs. msrc.microsoft.com remains DNS-blocked in this session so per-CVE Microsoft advisories were not read directly; counts cross-verified across Tenable, CrowdStrike, Rescana, Qualys, ZDI, Dark Reading, CSO. Source disagreement: CrowdStrike cites 1,252 / 68 Critical vs. Tenable/CSO's 1,093 / 63 — the gap likely counts republished Chromium-source CVEs differently.
- **Barracuda ESG pre-auth root RCE chain — CVE-2026-116606 + CVE-2026-111560 — on KEV in-window (deadline 2026-11-13, two days).** Barracuda rates the auth-bypass CVE-2026-116606 CVSS 9.3; Mandiant/community score the full chain Critical/CVSS 9.8. Barracuda confirmed exploitation against "a small number of organizations" on 2026-11-09, and a public PoC is circulating (watchTowr Labs). Bypass lives in ESG password-change logic; command injection is in the timezone field. ESG is the only Barracuda product hit pre-auth; WAF/ADC/Archiver are authenticated-admin injection only. Fixed firmware builds disagree across sources (9.4.0.029 / 9.4.0.030 / 9.4.017) — read Barracuda's trust-portal table before patching.

## Telecom

**Cisco BroadWorks out-of-band blind XXE — CVE-2026-20320 — KEV addition in-window** · [HIGH]
Advisory **cisco-sa-bworks-xxe-uwUd7CEt**. CWE-611 in the Open Client Interface (OCI) XML Parser. An unauthenticated remote attacker that can reach the OCI service can submit crafted XML that causes the parser to resolve external entities, reading sensitive configuration data (secondary sources describe the attack target as OCI-P / Provisioning). CVSS 7.5 (Cisco). Affected: BroadWorks releases earlier than **RI.2026.07** on supported platforms. Fix: upgrade to RI.2026.07 or later. **No workarounds.** Originally published 2026-08-19 as "no known exploitation"; CISA added to KEV 2026-11-10 with federal deadline 2026-11-24. Reported by Sandesh M Gawai. Operator action: inventory BroadWorks Application Server / Profile Server deployments (hosted-PBX, UCaaS, and the carrier-hosted enterprise-voice offerings reselling BroadWorks under operator brands), confirm whether OCI is network-reachable from untrusted zones, patch to RI.2026.07+. BroadWorks presence is very broad across Tier-1 and Tier-2 telecoms globally — a KEV listing with a 14-day window is the loudest signal for BroadWorks since the 2023 AuthService chain.

**Openwave Webtop Media Transcoder — CVE-2026-111793 — KEV addition in-window** · [NOTABLE]
JVNVU#93403064 / Openwave advisory. CWE-669 (incorrect resource transfer between spheres). The transcoder does not enforce the admin-configured file-type limits applied by the Webmail front-end; an authenticated user that invokes the transcoder directly can convert document types outside policy. CVSS 4.3. Fixed in **1.1.22.0**; vendor also directs customers to the latest Media Server 2.0. JVN explicitly cites developer-observed exploitation; KEV addition 2026-11-10 (deadline 2026-11-24). Telecom relevance is the product footprint — Openwave Messaging is the webmail / mailstore stack at a large share of global operator consumer-email services and large enterprise mail estates — not the primitive, which is file-type bypass rather than RCE. Impact scenarios: malicious-document conversion pipelines inside carrier mailstore to probe downstream renderer / preview services, or policy-evasion for exfil of restricted document types. Operator action: identify Media Transcoder instances (often deployed as internal microservice behind Webtop), patch, audit transcoder access logs for non-Webtop invocation.

**Microsoft Patch Tuesday — November 2026 — 1,093 CVEs, 63 Critical, one exploited zero-day** · [CRITICAL]
Landed on schedule 2026-11-10 ~18:00 UTC, cleanly in the digest window. msrc.microsoft.com is DNS-blocked in this session; counts and CVE IDs cross-verified across Tenable, Rapid7, Qualys, ZDI, CrowdStrike, Rescana, CSO Online, Dark Reading. Source disagreement is notable: CrowdStrike reports 1,252 / 68 Critical; Tenable / Rapid7 / CSO / Redmondmag report 1,093 / 63 Critical / 1,029 Important / 1 Moderate; Trinetriops reports 1,094 / 64 Critical. The ~160-CVE gap is almost certainly due to how CrowdStrike counts republished Chromium-sourced CVEs. The anchor is the Tenable/CSO count.
Named critical RCEs / privilege-escalations worth near-term attention across any mixed enterprise estate (includes telco operator-support IT, roaming-agreement systems, corporate AD):
- **CVE-2026-124194 — Microsoft Outlook spoofing — exploited zero-day, CISA KEV added 2026-11-10 (deadline 2026-11-24).** Missing user-interaction check allows an unauthorized network attacker to perform spoofing; practical impact is NTLMv2 hash exposure via outbound auth to an attacker-controlled destination. CVSS ~6.5 (Microsoft "moderate" per Qualys). Behaviour family is CVE-2023-23397 and CVE-2026-21260; disable outbound SMB / NTLM to untrusted destinations as the enduring mitigation.
- **CVE-2026-119958 — Windows LDAP RCE CVSS 9.8.** Unauthenticated, no user interaction; out-of-bounds write in the LDAP service. Microsoft rates "Exploitation Less Likely" but the practical impact on domain controllers is the top-of-stack concern — any directory service reachable from an untrusted segment is in scope.
- **CVE-2026-116928 — Windows Search RCE CVSS 9.8.** Rapid7 / Rescana name this as Windows Search (one secondary source mis-ties it to Exchange).
- **CVE-2026-119952 — Windows Schannel RCE CVSS 8.1.** TLS-stack timing discrepancy; Microsoft rates **"Exploitation More Likely"**. Prioritize over the higher-CVSS LDAP item on externally-facing TLS endpoints.
- **CVE-2026-118207 — Exchange Server RCE CVSS 8.8.** External-control-of-file-path path; Pwn2Own-originated (ZDI-26-535).
- **CVE-2026-109469 — Entra Device Registration EoP CVSS 10.0.** Highest-scored item in the batch; identity-plane impact — Entra-joined device compromise cascades into Conditional Access bypass.
- **8 × critical Hyper-V EoP CVEs** — hypervisor-level EoP cluster; prioritize on multi-tenant hosts.

**Barracuda ESG pre-auth root RCE chain — CVE-2026-116606 + CVE-2026-111560 — KEV, exploited, deadline 2026-11-13 (T-2)** · [CRITICAL]

Operator action: inventory Barracuda ESG, WAF, ADC, Archiver; apply fixed firmware; on ESG, assume compromise if any administrative-looking configuration changes were made in the six weeks before patch; rotate any credentials, API keys, or SMTP relay auth stored on-appliance; hunt for anomalous outbound from ESG mgmt NIC.
