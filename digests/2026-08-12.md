## Telecom

- **Cisco Secure Firewall ASA/FTD — `CVE-2026-20349` added to CISA KEV
  (2026-08-11).** Unauthenticated remote attacker sends a crafted HTTP request
  to the Remote Access SSL VPN service; heap inspection error → device reload
  (DoS). CVSS 8.6. Vulnerable configs include SSL VPN, IKEv2 RA VPN with
  client services, and ZTNA on FTD. Cisco PSIRT confirms active exploitation.
  Why telco practitioners care: ASA/FTD are widely deployed at operator MPE,
  MEC, and enterprise-edge; a signaling-plane DoS via the internet-facing
  management/VPN surface is a viable pre-position tactic. Patch and audit any
  SSL-listen-socket exposure. [CISA KEV entry](https://www.cisa.gov/news-events/alerts/2026/08/11/cisa-adds-three-known-exploited-vulnerabilities-catalog) — 2026-08-11 — **CRITICAL**
- **No new GSMA FS.11/FS.19 advisory or SS7/Diameter/GTP/N32 disclosure in the
  window.** The Citizen Lab surveillance-vendor telecom exploitation research
  from April 2026 continues to circulate but nothing new landed today; see
  Notes.

## General high-severity

- **Microsoft August Patch Tuesday — `CVE-2026-68820`, exploited zero-day.**
  Use-after-free in `afd.sys` (Ancillary Function Driver for WinSock) →
  local elevation of privilege to SYSTEM via race condition. CVSS 7.0
  (Important). Check Point attributes in-the-wild use to Lazarus (DPRK) as an
  LPE stage to load a new **FudModule** kernel rootkit variant. Present on
  essentially every Windows host. [Tenable](https://www.tenable.com/blog/microsofts-august-2026-patch-tuesday-addresses-398-cves-cve-2026-68820) · [The Register](https://www.theregister.com/security/2026/08/11/421-bugs-in-microsofts-patch-tuesday-release-and-the-norks-have-already-attacked-one/5286483) — 2026-08-11 — **HIGH**
- **SAP Commerce Cloud Data Hub Adapter — `CVE-2026-58231`, CVSS 10.0.**
  Improper authorization on the Data Hub import endpoint; unauthenticated
  attacker with network reach can submit crafted payloads → arbitrary code
  execution, credential and customer-order data exposure. Affects `COM_CLOUD`
  2211 and 2211-JDK21. Patch on an emergency schedule. [SecurityWeek](https://www.securityweek.com/sap-patches-critical-code-injection-memory-corruption-vulnerabilities/) · [CSO Online](https://www.csoonline.com/article/4208185/patch-tuesday-august-2026-a-zero-day-winsock-driver-hole-under-exploit-and-a-maximum-severity-sap-vulnerability.html) — 2026-08-11 — **CRITICAL**

## Worth watching

- **DPRK · Lazarus FudModule rootkit refresh.** The `CVE-2026-68820`
  exploitation is the second known WinSock-AFD zero-day Lazarus has burned
  for FudModule bring-up; treat as ongoing kernel-tampering campaign, not a
  one-off. Windows EDR telemetry gap on kernel-mode driver behavior is the
  operative weakness. Watch for follow-on IOCs from CheckPoint / Kaspersky /
  Microsoft MTAC.
- **Cisco ASA/FTD attack cluster.** CISA and Cisco continue to signal an
  active attack chain against Cisco firewalls (see Cisco's standing "Continued
  Attacks Against Cisco Firewalls" resource page). Today's KEV entry fits the
  same operator- and enterprise-edge target set. Anyone running RA SSL VPN
  should treat this as an in-flight campaign, not a routine patch.
- **Metabase blast radius.** SaaS/BI vendors that host Metabase or wrap it
  behind auth proxies remain exposed if not on the fixed line. Expect more
  downstream customer-data notifications over the next 1–2 weeks (n8n was
  first out of the gate).
- **Ransomware group with DPRK ties targeting unpatched Fortinet edge**
  (US–Korea joint alert circulating this week; not new CVE content, but
  reinforces that any Fortinet gear last touched pre-2025 is a live target).
