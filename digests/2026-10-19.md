## Worth watching
- **PEERSTITCH on a telecom MSP (Unit 42 / Palo Alto Networks, disclosed 2026-10-14).** Memory-resident ARM64 malware deployed on a managed service provider that resells firewall/managed-security services to telcos and others. Initial access via FortiJump (CVE-2024-47575, FortiManager missing-auth, Oct 2024); privilege/persistence via FortiOS auto-script path traversal CVE-2025-61624 (patched April 2026). PEERSTITCH leaves no on-disk binary, no listening port, and no outbound-initiated connection — it piggybacks C2 on legitimate `/bin/miglogd` and `/bin/iked` traffic, which defeats most IDS signature triggers. Exposure: credentials and configs for 500+ downstream customer firewalls. Patching does not evict the implant; defenders need memory forensics and credential rotation. [[Unit 42](https://unit42.paloaltonetworks.com/fortimanager-cve-2024-47575-peerstitch-malware.md)] [[The Hacker News](https://thehackernews.com/2026/10/attackers-exploit-fortios-flaw-to.html)] [[Security Affairs](https://securityaffairs.com/?p=201077)] — Severity: **HIGH** (telecom-adjacent, nation-state-grade tradecraft).
- **UNC7017 / AOMEI Backupper + AnyViewer supply-chain compromise (GTIG + ManageEngine, disclosed 2026-10-16).** Attackers tampered with the files AOMEI's own update servers served, in 5–10 minute windows between May and July 2026, so only clients that checked for updates during one of those windows pulled the backdoor. Payload: a `CROSSROAD` downloader staging a Radmin folder, scheduled task every 3 hours, DLL side-load delivering an encrypted pocketpy implant; downloader self-deletes. AOMEI has patched the server side, but that does not clean already-infected hosts. Scope: ManageEngine confirmed the chain on AOMEI Backupper v8.3.0; GTIG also names AnyViewer as using the same update flow. Separate but related: **CVE-2026-12780**, LPE in `amwrtdrv.sys` (versions ≤8.3.0 per vendor; CERT/CC adds v6.4.0). [[The Hacker News](https://thehackernews.com/2026/10/attackers-tampered-with-aomei.html)] [[ManageEngine Lab](https://www.manageengine.com/threat-analysis-lab/aomei-backupper-supply-chain-compromise.html)] — Severity: **HIGH**.
- **Atlassian CVE-2026-21589 (unauth arbitrary file read; CISA KEV add 2026-10-16).** Disclosed Oct 5; exploitation attempts began within two hours of watchTowr publishing technical details + PoC on Oct 6. Affects self-hosted Bitbucket, Confluence, Jira Software/Service Management, Bamboo, Crowd, Crucible, Fisheye (Cloud auto-patched). Exploitation requires knowing an exact file path, so impact depends on predictable config/secret paths. For a telco red-team: Jira/Confluence are frequent harvesting grounds for API tokens, SSH keys, and signalling-firewall policy exports. [[eSecurity Planet](https://www.esecurityplanet.com/news/news-atlassian-cve-2026-21589-file-read-flaw/)] [[Security Affairs](https://securityaffairs.com/?p=201086)] — Severity: **CRITICAL** (CISA KEV).
- **Rejetto HFS CVE-2026-61500 under active exploitation (VulnCheck tracker; exploitation start 2026-10-01).** Affects HFS 3.0.0–3.2.0. Session-signing key derived from a non-cryptographic RNG → key recovery → forged admin session → RCE via `server_code`. Public PoC published by Horizon3 on 2026-09-30. CVSS 4.0 scores range 9.3–9.8 across sources. VulnCheck observed ~100 internet-facing instances. Likely to be used as initial-access-for-rent on internet-facing lab/share servers. [[eSecurity Planet](https://www.esecurityplanet.com/cybersecurity-threats/news-rejetto-hfs-cve-2026-61500-exploitation/)] — Severity: **HIGH**.
- **Cisco SD-WAN Manager CVE-2026-76504 (CVSS 9.8, auth bypass; disclosed 2026-09-30, KEV-listed).** Still being exploited; Cisco became aware via a TAC case in September. Affects Catalyst SD-WAN Manager (ex-vManage) releases 20.9–26.2; no workaround. Any instance reachable from an untrusted network in September should be treated as potentially compromised — patching blocks the bypass but does not remove existing admin footholds. Telcos running managed SD-WAN services for enterprises should re-audit admin accounts, API tokens, and template exports. [[Help Net Security](https://www.helpnetsecurity.com/2026/10/01/new-cisco-sd-wAN-zero-day-exploited-in-the-wild-cve-2026-76504/)] [[CSA Research Note](https://labs.cloudsecurityalliance.org/research/csa-research-note-cisco-sdwan-cve-2026-76504-20261002-csa-st/)] — Severity: **CRITICAL**.
- **ConnectWise Cloud Backup / M365 OAuth token theft (reported ~2026-10-14, 173 tenants per Tech Insider; unverified against ConnectWise/Huntress primaries).** Huntress reportedly observed a compromised Microsoft 365 API credential belonging to the Cloud Backup application being used to pull Microsoft Graph access tokens from customer tenants.
