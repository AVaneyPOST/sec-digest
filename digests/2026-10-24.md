## Telecom

- **Cisco Expressway Series — critical unauth RCE as root (CVE-2026-76466, CVSS 9.8)**
  [NOTABLE→HIGH]. Flaw in the database service: persistent cookies plus insufficient client
  certificate validation when TLS Verify Mode is enabled for clustering. Both Expressway-C
  and Expressway-E are affected; no workarounds published. Why it matters for a telco /
  offensive-security practitioner: Expressway is the standard MRA / SIP traversal edge for
  enterprise UC and for operator-hosted collab offerings. An unauth RCE on this box lands
  you on the signalling edge, with routes toward Unified CM / IMS-adjacent trunking and
  often outbound to internal SIP cores. Treat any internet-facing Expressway as burning
  until patched. Disclosed 2026-10-21 in Cisco's Oct bundle; secondary coverage carried
  through 2026-10-23.
  [OpenCVE entry](https://app.opencve.io/cve/CVE-2026-76466),
  [Cybersecurity News writeup](https://cybersecuritynews.com/critical-cisco-expressway-vulnerability/).

- **Oracle Communications Cloud Native Core — CPU October 2026** [NOTABLE]. Oracle's Oct 20
  CPU covers multiple Oracle Communications CNCF components (Policy, Network Repository
  Function, Security Edge Protection Proxy, etc. — the full breakdown wasn't visible in
  what we could fetch). Why it matters: SEPP sits on N32 between PLMNs, NRF is the SBA
  service directory, and the Policy function brokers 5G QoS/charging. A fixable bug in any
  of these affects the 5G core trust boundary. Treat as high priority for lab-first testing
  this week. Canadian Cyber Centre summary AV26-1071 dated 2026-10-20.
  [cyber.gc.ca AV26-1071](https://cyber.gc.ca/en/alerts-advisories/oracle-corporation-security-advisory-av26-1071).

- **HPE ArubaOS — 72 CVEs, 8 maximum-severity (auth bypass + code execution)** [HIGH].
  Covered by BleepingComputer on 2026-10-23. Not a core-telecom product but widely deployed
  as operator corporate / retail WLAN and as the WLAN under enterprise private-5G
  deployments, so it is operationally relevant for a mobile operator's own estate. Patch
  details were not fully readable from this environment — see `## Notes`.
  [BleepingComputer homepage ref](https://www.bleepingcomputer.com/).

## General high-severity

- **CISA KEV addition: CVE-2026-110447 — Collabora Online built-in CODE server OS command
  injection** [CRITICAL]. Added 2026-10-23 on evidence of active exploitation. Collabora
  Online is the LibreOffice-based document editor bundled into Nextcloud and other
  self-hosted collab stacks, so expect wide blast radius in SMB and public-sector tenants.
  Enumerate instances, patch, and look for recent child processes of the WOPI / coolwsd
  worker.
  [CISA alert index 2026-10-23](https://www.cisa.gov/news-events/alerts/2026/10/23/cisa-adds-one-known-exploited-vulnerability-catalog-0).

- **PHP RCE pair — CVE-2026-109618 and CVE-2026-109619 (CVSSv4 9.2)** [CRITICAL]. Both
  allow unauthenticated remote code execution with web-worker privileges via the
  `session.upload_progress` handler path; one is an out-of-memory corruption, the other a
  stale global state issue. Fixed in PHP 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12 (2026-10-21).
  CISA's alert and Unit 42's threat brief were both updated on 2026-10-23 — CISA added a
  SIGMA detection rule. Disabling `session.upload_progress.enabled` is a stopgap only;
  mod_php is the highest-risk configuration. Still-unpatched PHP fleets are the active-
  exploitation watch item for the next 72 hours.
  [Unit 42 brief](https://unit42.paloaltonetworks.com/cve-2026-109618-cve-2026-109619/),
  [Rapid7 writeup](https://www.rapid7.com/blog/post/etr-cve-2026-109618-and-cve-2026-109619-critical-unauthenticated-remote-code-execution-in-php/),
  [Ox Security details](https://www.ox.security/blog/cve-2026-109618-cve-2026-109619-two-vulnerabilities-allow-unauthenticated-rce-in-php/).

- **Quest Diagnostics — Quanum LSM intrusion** [HIGH]. 8-K filed 2026-10-21: unauthorised
  access to the Quanum LSM clinician portal (test ordering + results lookup). Federal law
  enforcement notified, external IR engaged, scope still open. Patient records affected
  but types/counts not yet disclosed. News coverage continued through 2026-10-23.
  [Quest 8-K (SEC)](https://www.sec.gov/Archives/edgar/data/0001022079/000094787126000941/ss6979200_8k.htm),
  [BleepingComputer coverage](https://www.bleepingcomputer.com/news/security/quest-diagnostics-confirms-data-breach-exposed-patient-records/).
