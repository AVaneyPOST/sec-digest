## General high-severity
- **PHP Core — CVE-2026-109618 and CVE-2026-109619 ("PHP2Shell"), disclosed 2026-10-21.** Two linked bugs in the PHP core request lifecycle:
  - **CVE-2026-109618 (CVSS 9.2):** Out-of-memory handling can interrupt PHP while request data is partially initialized; cleanup then treats invalid data as valid.
  - **CVE-2026-109619 (CVSS 9.2):** Request-owned internal state can survive after its memory is freed and be reused by a later request on the same worker — classic UAF with cross-request bleed on long-lived workers (PHP-FPM, mod_php, swoole-style setups).
  - **Affected:** every PHP release from **5.4 through 8.5.11** — "every PHP version released in the last decade" per Wiz. **Patched:** 8.5.12, 8.4.27, 8.3.36, 8.2.35. **Unpatched:** PHP 8.1 and earlier (EOL; must upgrade).
  - Pre-disclosure Hacker News post + screenshots circulated Oct 20 before the Oct 21 14:00 UTC release; Cloudflare and watchTowr are reportedly seeing exploitation attempts. Google Cloud's blog confirms Mandiant hunting and 23 curated detections in Google Security Operations.
  - Discovered by Wiz Research; PHP project issued the fixes on Oct 21.
  - Operator impact: PHP is the glue for most self-service portals, MVNO front-ends, OSS/BSS web layers, provisioning dashboards and anything built on WordPress/Drupal/Laravel/Magento in a carrier estate. Prioritize anything internet-facing and anything on long-lived FPM workers.
  - [[Google Cloud blog — Responding to core PHP vulnerabilities](https://cloud.google.com/blog/products/identity-security/responding-to-core-php-vulnerabilities-cve-2026-109618-cve-2026-109619)] [[Phoenix Security writeup](https://phoenix.security/php-core-rce-cve-2026-109618-109619-critical-remote-code-execution/)] [[Huntress Rapid Response](https://www.huntress.com/blog/php2shell-leaked-critical-php-vulnerabilities)] [[Tenable FAQ](https://www.tenable.com/blog/php2shell-cve-2026-109618-cve-2026-109619-frequently-asked-questions-about-critical-php-remote)] [[Wiz Research](https://www.wiz.io/blog/php2shell-php-rce)] [[Namecheap incident status](https://www.namecheap.com/status-updates/ongoing-php-security-vulnerability-affecting-hosting-services-october-21-2026/)] — Severity: **CRITICAL**.
- **Cisco Snort 3 Security Hardening Release — `cisco-sa-hardening-snort3-ybgmhTQe`, Critical, published 2026-10-21 16:00 GMT.** Three CVEs: CVE-2026-20043, CVE-2026-20236, CVE-2026-20291 across Snort 3 integrations in multiple Cisco products. Internally found; no known public exploitation. Software updates available, no workarounds. Snort 3 is embedded across Secure Firewall, Firepower, FTD and Catalyst security services — this often lands as a cross-product cluster.
