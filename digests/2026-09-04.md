## General high-severity

- **Broadcom VMSA-2026-0007 — VMware Workstation / Fusion VM-escape (CVE-2026-59346, CVSS 9.3; CVE-2026-59347, CVSS 8.1).** [CRITICAL] Integer overflow in the **VMXNET3** virtual NIC lets a local admin inside a guest VM execute code on the host — a full VM isolation break. Companion HGFS stack-overflow issue rated 8.1 affects Workstation 25H2 / 26H1 (any host OS) and Fusion 25H2 / 26H1 on macOS. **No workarounds — patch to 26H1u1.** Practitioner impact: any red-team practice image, malware-analysis sandbox, or per-developer nested-lab environment running Workstation / Fusion is currently isolation-broken; especially painful for MSSP / IR shops that hand engineers per-case Workstation VMs on shared hosts. Published 2026-09-03. Not known-exploited at publication. [Broadcom VMSA-2026-0007](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/38288) · [CyberSecurityNews](https://cybersecuritynews.com/vmware-workstation-and-fusion-vulnerabilities/) — 2026-09-03
- **JFrog Artifactory CVE-2026-82329 — active exploitation on self-hosted instances, per watchTowr.** [CRITICAL] Unauthenticated attackers use the improper-authentication flaw (CVSS 9.8) to **mint themselves admin tokens** and then enumerate users, groups, credentials and federated-access relationships — i.e. a full self-hosted-Artifactory takeover, with the natural follow-on being poisoned artifacts pushed into downstream build/deploy pipelines. Patched 2026-08-28 in the 7.111.21 / 7.117.28 / 7.125.20 / 7.133.29 / 7.146.38 / 7.161.20 trains; SaaS not affected. Added to CISA KEV 2026-09-02; exploitation reporting hits mainstream on 2026-09-03. If you host Artifactory internally and haven't patched, treat any admin-token minted since 2026-08-28 as suspect.
