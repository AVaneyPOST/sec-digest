## General high-severity

- **SAP Commerce Cloud CVE-2026-58231 (CVSS 10.0) — active exploitation carries into 15 Aug, still no public PoC [CRITICAL]** — Insufficient authorisation + missing input validation in the Data Hub Adapter → unauthenticated RCE on SAP Commerce Cloud `COM_CLOUD 2211` / `COM_CLOUD 2211-JDK21`. SAP patched 11 Aug (Security Patch Day); Defused's honeypots caught the first weaponised submissions on 14 Aug, and inbound activity was still being logged into 15 Aug against exposed Data Hub Adapter endpoints on port 443, with traffic originating from hosting infrastructure tied to Charlotte Colocation Center (AS11402). Notably, no public PoC has been released — an attacker with private capability is burning it against production estates. Patch to the fixed release or block the Data Hub Adapter behind SAP's IP Filter Sets so only trusted Data Hub systems can reach it; blast radius is much wider than the storefront, because Commerce Cloud typically fronts loyalty, billing, identity and CDP backends. [Onapsis SAP Patch Day writeup](https://onapsis.com/blog/sap-security-patch-day-august-2026/) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/max-severity-sap-commerce-cloud-flaw-now-targeted-in-attacks/) · [The Hacker News](https://thehackernews.com/2026/08/sap-commerce-cloud-flaw-could-let.html) · [SOCRadar CVE-2026-58231 primer](https://socradar.io/blog/sap-commerce-cloud-cve-2026-58231/) · [eSecurity Planet](https://www.esecurityplanet.com/threats/sap-commerce-cloud-rce-flaw-actively-exploited/) · [FieldEffect exploitation report](https://fieldeffect.com/blog/active-exploitation-sap-commerce-cloud-vulnerability) — carrying into 15 Aug 2026.
