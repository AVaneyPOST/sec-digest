## Telecom

- **MikroTik RouterOS — CVE-2026-14227 (insufficient session expiration, ICSA-26-211-01, published 30 Jul).** CWE-613. Vendor confirms all RouterOS versions affected per the CISA advisory summary. Attack path: a low-privilege API session retains its previous permission set after an inactivity timeout or after the corresponding user's group is downgraded — so an attacker who already has any authenticated API foothold (leaked technician credentials, weak/default read-only account, credential-stuffed operator login) can escalate at the moment of a permission change and read the WireGuard private key material in the clear. Consequence: complete VPN impersonation of the router (site-to-site, road-warrior, or MVNO backhaul tunnels), decryption of all associated traffic (past-captured and future). Telecom read: this hits at least three real operator patterns — (a) small-ISP / WISP core routers exposed on management VLANs shared with support-tools access, (b) MVNO / regional-carrier VPN concentrators terminating remote engineer sessions or roaming-support tunnels, (c) rural / municipal fixed-wireless deployments where RouterOS is the CPE. Mitigation: apply the RouterOS fix once available, restrict `/ip service` API to management VRF / ACL-list, rotate WireGuard peer keys as if leaked, and audit the RouterOS user log for sessions that survived group changes. No public in-wild exploitation confirmed in the 24h window. [CISA ICSA-26-211-01 (primary)](https://www.cisa.gov/news-events/ics-advisories/icsa-26-211-01), [penligent.ai analysis (uses a different CVE ID)](https://www.penligent.ai/hackinglabs/cve-2026-59108/). Date: 2026-07-30. [HIGH]

## General high-severity

- **Brinks Home data-breach confirmation and ShinyHunters extortion — 30 Jul.** Brinks disclosed intrusion identified 20 Jul; ShinyHunters simultaneously listed the company on their data-leak site claiming 4.9M Salesforce PII records exfiltrated. Coordinated disclosure by Noma Security's Noma Labs 30 Jun → private fix 24h later → public disclosure 29 Jul; fixed in Ruflo 3.16.3 (MCP bridge now loopback-bound by default, `terminal_execute` gated behind server-side executeTool controls, MongoDB auth mandatory).
