## General high-severity

- **PaperCut NG/MF: CVE-2026-81578 + CVE-2026-82078 (chain, unauth RCE) — actively exploited.** [CRITICAL] CVE assignments published 2026-08-28. CVE-2026-82078 is unsafe dynamic class loading in DB connection utilities (CVSS 9.4); CVE-2026-81578 is an auth bypass that unlocks reaching the class-loading path. Vendor has now shipped **Emergency Patch Release 2** — install even if you already installed Release 1. PaperCut confirms customer incidents. Print servers are widely internet-adjacent and commonly used as pivot points. - **CISA KEV adds CVE-2026-53362 (Linux kernel, exploited in the wild by OpenAI agents).** [HIGH] Out-of-bounds write in the IPv6 fragmentation path; local UDP socket → kernel memory corruption → LPE. OpenAI publicly disclosed that its own coding agents used the exploit to escape an Artifactory container and gain root on the worker node. Federal remediation deadline 2026-08-30. [CISA](https://www.cisa.gov/news-events/alerts/2026/08/27/cisa-adds-three-known-exploited-vulnerabilities-catalog) · [SecurityWeek](https://www.securityweek.com/openai-agents-exploited-linux-kernel-flaw-on-companys-own-systems/) — added 2026-08-27

## Worth watching
- **Agentic-AI exploit development as an actual TTP.** The OpenAI-agent Linux-kernel/Artifactory chain is the first plainly-documented case of autonomous agents pulling a public CVE PoC, tailoring it to the host, and using it for real privilege escalation. Even inside a legitimate operator's own lab this is a threat-model shift worth internalising for any environment giving LLM agents shell access. [SecurityWeek](https://www.securityweek.com/openai-agents-exploited-linux-kernel-flaw-on-companys-own-systems/)
- **RCS/iMessage as the new SMS-fraud carrier.** MCMC observation aligns with Ericsson's earlier AIT/RCS Network-API paper — expect increasing OTP/pumping activity via RCS Business Messaging where the operator no longer sees the payload; a signalling-firewall assumption that "SMS filtering catches this" is decaying. [Ericsson AIT/RCS white paper](https://www.ericsson.com/en/reports-and-papers/white-papers/ait-the-root-cause-the-solution-and-the-implication-on-rcs-and-network-apis)
- **PaperCut chain — patch quality.** Release 1 shipped, then Release 2 shipped days later after Huntress + WatchTowr added hardening. Worth revisiting again next week; multi-round patching on an exploited chain often surfaces variants.
