## General high-severity

- **[HIGH, unverified primary] CISA KEV additions reported 2026-10-28 — CVE-2026-46300 "Fragnesia" (Linux kernel) + CVE-2026-41709 (VMware ESX).** Secondary tracker (securityonline.info) says CISA added both on Oct 28 with federal remediation deadlines of 2026-10-31 (kernel) and 2026-11-11 (ESX). CVE-2026-46300 is a well-documented local privilege escalation in the Linux kernel's XFRM ESP-in-TCP path (nicknamed "Fragnesia"); any unprivileged user → full root on kernels built before 2026-05-13. PoC exploit code has been on GitHub since 2026-05-14 and distros (Fedora, SUSE, Oracle) shipped patched kernels in May–June. CVE-2026-41709 is listed as a VMware ESX flaw; no further detail surfaced from secondary sources. **Primary verification pending** — www.cisa.gov is unreachable from this environment at digest time. Date: 2026-10-28 (per secondary). [securityonline.info summary](https://securityonline.info/cisa-kev-linux-kernel-php2shell-vmware-esx/) · [CVE-2026-46300 technical overview (secondary)](https://vuln.today/articles/cve-2026-46300-fragnesia-cve-202646300-new-linux-kernel-vulnerability-grants-roo). Severity: **HIGH** (kernel LPE with public exploit, long-patched → anything still unpatched is low-hanging fruit); **CRITICAL** on the ESX side if the ESX item is in fact unauth-RCE class (unverified).

- **[HIGH] Oracle E-Business Suite CVE-2026-101767, CVSS 9.8 — exploratory probing observed 2026-10-27.** Oracle's October 2026 CPU (2026-10-20) fixed an unauthenticated SQL-injection → RCE class flaw in the EBS Application Object Library (Core) component. Horizon3 reported the issue. Defused Cyber reported on 2026-10-27 that its EBS decoys recorded "exploratory exploit" traffic — i.e. attackers testing payloads, not yet broad weaponisation. The separate Payments-module flaw CVE-2026-46817, also in the October CPU, has been under active exploitation since earlier in October and is already in CISA KEV; several hundred EBS instances remain internet-exposed. The 101767 scanning adds urgency to the whole EBS 12.2.x patch bundle — treat the October CPU as time-boxed, not routine. Date (exploratory probe): 2026-10-27 (edge of window). [The Register coverage](https://www.theregister.com/security/2026/10/28/oracle-celebrates-end-of-cybersecurity-awareness-month-with-quadruple-trouble/5306121) · [Rescana writeup](https://www.rescana.com/post/oracle-e-business-suite-cve-2026-101767-prepare-now) · [SecurityAffairs on EBS 46817 exploitation](https://securityaffairs.com/194599/security/oracle-e-business-suite-flaw-under-active-attack-950-systems-exposed.html). Severity: **HIGH** for 101767 standalone (probes, no confirmed in-wild RCE yet); **CRITICAL** when considered alongside 46817's confirmed exploitation.
