## Telecom

**SignalWire FreeSWITCH SIP MESSAGE RCE — CVE-2026-116779 — KEV, exploited in the wild** · [CRITICAL]
Command injection (CWE-77) in `sofia_presence_handle_sip_i_message`. A crafted SIP MESSAGE whose `To` header carries a `+` splits inside the handler and reaches FreeSWITCH's API, letting an unauthenticated attacker read configuration/credentials, hijack call control, and run OS commands as the FreeSWITCH service account. Affected: **FreeSWITCH ≤ 1.11.2**. Fix: **1.11.3** (upstream advisory GHSA-mg63-h38w-8p9p). CVSS 9.8 per SignalWire; VulDB 10.0. KEV added 2026-11-09 with federal deadline 2026-11-12 (three days). Operator action: inventory every FreeSWITCH deployment (SBC footprint, class-5 soft-switches at smaller carriers and MVNOs, IVR, conferencing, voicemail, WebRTC gateways, and the FreeSWITCH-based commercial products — FreeSWITCH is the engine inside several SBC/UCaaS stacks), patch to 1.11.3 or apply SignalWire's workarounds, and block ingress SIP MESSAGE where it is not a required feature. SignalWire has not published IOCs; derive detections from unexpected shell children of the FreeSWITCH process and SIP MESSAGE traffic carrying suspicious `To` user strings. CVE-2026-116785 and CVE-2026-116790 were disclosed alongside this one and are not currently flagged exploited; patch together.

**OpenSSH on musl libc authentication bypass — CVE-2026-123158 ("sshhole") — KEV in-window** · [HIGH]
Password-length confusion in sshd on Linux built against musl libc without PAM. Passwords between 256 and 1024 characters are misinterpreted as valid SHA-crypt hashes, so any password in that length band is accepted on an account that carries a real SHA-crypt hash. Direct root login further requires `PermitRootLogin yes`. CVSS 3.1 of 8.1. Fix: **OpenSSH 10.6p2** (upstream, released 2026-11-05). Alpine shipped backports that keep the OpenSSH version number — update by **package revision** (`apk info openssh` and compare against e.g. `10.3_p1-r2` on Alpine 3.24, `10.0_p1-r11` on Alpine 3.22). `sshd` must be restarted for the fix to take effect; a package upgrade alone is not sufficient. CISA added to KEV 2026-11-09 (deadline 2026-11-12). SANS Internet Storm Center reports honeypot SSH login attempts matching the signature in-window; success count not disclosed. Mitigation if unable to patch: `PasswordAuthentication no` + `sshd` restart, after validating key-based login. This is the item I flagged yesterday as "not on CISA KEV" — status has moved. Telecom-adjacent angle: Alpine base images are common in NFV sidecars, service-mesh data planes, telco container build chains — inventory accordingly and raise priority in any environment where key-based auth isn't fully enforced.
[source](https://raw.githubusercontent.com/cisagov/kev-data/main/known_exploited_vulnerabilities.json) · [source](https://www.stepsecurity.io/blog/cve-2026-123158-sshhole-openssh-musl-password-bypass) · Date: 2026-11-09 (KEV addition, in-window)
