## General high-severity

**AmnesiaStealer — new macOS infostealer with live browser-session hijack** — [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-amnesiastealer-macos-malware-hijacks-browser-sessions-via-remote-control/), [SecurityWeek](https://www.securityweek.com/amnesiastealer-macos-malware-steals-data-controls-browser-sessions/), [Jamf Threat Labs (research, dated 2026-08-13)](https://www.jamf.com/blog/amnesia-stealer-macos-infostealer-clickfix/) — press wave 2026-08-16 — **NOTABLE**
Multi-stage Rust infostealer delivered via ClickFix-style fake GitHub pages that instruct victims to paste a Base64-encoded Terminal command. Beyond typical credential/keychain/wallet theft, it clones the victim Chromium profile into a hidden headless browser and streams the authenticated session live to the operator — effectively real-time session hijack of corporate SaaS, bypassing MFA and cookie-lifetime controls. Enterprise macOS fleet concern; underlying research is 3 days old but the coverage wave is in-window.

**Recap: Polish CHP plant OT breach via cross-tenant private APN (Sandworm-attributed, med confidence)** — [The Hacker News](https://thehackernews.com/2026/08/hackers-breach-polish-power-plant.html), [Security Affairs](https://securityaffairs.com/196955/security/hackers-cross-from-it-to-ot-through-a-private-apn-in-poland.html), [SC World](https://www.scworld.com/brief/attackers-breach-polish-chp-plant-using-private-apn-and-fortinet-device) — CERT Polska disclosure 2026-08-08, coverage through 2026-08-11/15

First real-world use of a private-APN carrier tenant as the OT pivot. Direct read-across for any operator selling private 5G / MPN slices: enforce per-tenant isolation, APN-layer segmentation, and NEF/AF egress controls.
