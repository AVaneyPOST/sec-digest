## General high-severity

- **CVE-2026-104286 — Fortinet FortiMail management-interface arbitrary file write (CVSS 9.8), zero-day exploited in the wild — BOD 26-04 federal remediation deadline is 2026-10-04 (24 hours out as of this window's close).** No new in-window vendor advisory or CISA update, but the deadline landing inside the next day makes this today's single highest-priority practitioner item. Unauthenticated, remote path traversal (CWE-22) combined with improper NULL-byte handling (CWE-158) in the management interface allows an attacker to write arbitrary files on the appliance via crafted HTTP(S) requests — the practical outcome is `.so` preload, webshell drop and configuration tampering, all pre-auth, all over the admin plane. **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. **Fixed:** 8.0.2, 7.6.7, 7.4.9. **Interim workaround** (Fortinet): disable the IBE (Identity-Based Encryption) feature and restrict management-interface access to trusted networks (`trusthost` / dedicated OOB only). **Vendor-published IOCs:** dropped files `/data/lib/liblog.so`, `/data/bin/webconsole`, `/data/bin/mailservice`, `/data/etc/ld.so.preload`; tampered artifacts `/bin/smit`, `/data/etc/httpd.conf`, `/data/migadmin.tar.gz`. Telecom-practitioner relevance: FortiMail is a common choice for carrier email relays, enterprise mail-gateway services sold to business customers, dealer / channel inboxes, NOC help-desk / ticketing-forwarders and MVNO back-office mail; any such appliance exposing its admin plane outside OOB is in scope today. Hunt scope: match the file-path IOCs against appliance file-system snapshots, pull `httpd.conf` / `ld.so.preload` deltas, review admin-plane HTTP(S) access logs for anomalous unauthenticated path components in the week leading up to 2026-10-01.
