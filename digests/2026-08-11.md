## General high-severity

- **Metabase zero-day — Framework / Tally / Kilo Code disclose
  stolen data (10 Aug aggregation)** — Help Net Security's 10 Aug
  update captured the widening customer-disclosure wave. Framework
  Computer: names, email, login IPs, billing/shipping addresses,
  phone numbers, company names. Tally: emails and password hashes.
  Kilo Code: partial or full user prompts, PII (name / email /
  billing address / location), Slack access tokens (invalidated on
  discovery). Vulnerability: pre-auth SQLi in
  `POST /api/session/reset_password`, CVSS 10.0, still no CVE
  assigned; vendor advisory `GHSA-vwf4-m7j8-wcjf`. Fixed self-hosted
  releases: 0.58.24, 0.59.21, 0.60.17, 0.61.11, 0.62.9, 0.63.5.
  Any operator BI/observability team running Metabase v1.58+ must be
  on a fixed release; if internet-exposed prior to patching, treat
  every connected-DB credential as burned.
  [Help Net Security](https://www.helpnetsecurity.com/2026/08/10/metabase-zero-day-framework-tally-kilo-code/)
  · [BleepingComputer](https://www.bleepingcomputer.com/news/security/framework-tally-disclose-metabase-data-theft-attacks/)
