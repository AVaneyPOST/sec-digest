## Telecom

- **Arista VeloCloud Orchestrator (VCO) — CVE-2026-93952 (CVSS 10.0), actively exploited, added to KEV 2026-09-22.** Improper input validation (CWE-20) in on-prem VCO lets an unauthenticated remote attacker reach privileged internal functionality and impact the orchestrator host — confidentiality, integrity and availability of both the orchestrator and the SD-WAN data it manages. The advisory is scoped to deployments where Edge-to-VCO authentication uses certificates (Certificate Acquire / Certificate Required modes; PSK deployments are not affected), and requires network access to the web UI plus the public part of an Edge cert. Fixed on the 5.2 and 6.4 trains; 6.1 and 7.0 fixes are pending; Arista's Hosted and Dedicated environments are already patched. Distinct from July's CVE-2026-16812 (unauth OS command injection, also 10.0). SD-WAN orchestrators are attractive because control of one gives control of every managed Edge — very relevant to any MNO/MSP/B2B carrier running or reselling VeloCloud SD-WAN. [Arista SA-0183](https://www.arista.com/en/support/advisories-notices/security-advisory/24765-security-advisory-0183) · [The Hacker News](https://thehackernews.com/2026/09/new-cvss-100-velocloud-orchestrator-flaw-actively-exploited.html) · [OffSeq threat page](https://radar.offseq.com/threat/cve-2026-93952-cwe-20-improper-input-validation-in-arista-networks-velocloud-orchestrator-vco-on-prem-25dafe8f246f1077) — 2026-09-22 — CRITICAL

- **F5 BIG-IP APM — CVE-2026-94127 (CVSS 9.8), actively exploited, added to KEV 2026-09-22.** Heap-based buffer overflow (CWE-122) in the OAuth profile handling of the Traffic Management Microkernel (TMM). Attacker-influenced input is written into a heap allocation without size validation, corrupting adjacent memory; the trigger is malicious HTTP traffic to any virtual server that has both an APM access policy and an OAuth profile. No credentials required, no management-plane exposure needed — this is a **data-plane RCE**. F5 shipped hotfixes and an emergency iRule for anyone who can't upgrade immediately. Telco relevance: BIG-IPs are load-balancing HTTPS in front of subscriber portals, IMS HTTP proxies, N32 SEPP fronts, and public APIs; APM+OAuth is exactly the deployment pattern for those. [F5 advisory (via SecurityOnline)](https://securityonline.info/big-ip-apm-vulnerability-cve-2026-94127/) · [DEV community writeup](https://dev.to/jeffreyciend/cve-2026-94127-what-f5-big-ip-operators-need-to-know-about-the-exploited-apm-flaw-hpi) · [Forkast analysis](https://forkast.news/the-oauth-profile-is-the-door-f5-big-ip-apms-heap-overflow-turns-a-network-security-appliance-into-an-unauthenticated-entry-point/) · [Field Effect summary](https://fieldeffect.com/blog/f5-fixes-big-ip-apm-vulnerability) — 2026-09-22 — CRITICAL

- **Check Point Quantum Security Gateway — CVE-2026-85102 (CVSS 9.8), and Quantum Security Management — CVE-2026-93616 (CVSS 9.8), both actively exploited, both added to KEV 2026-09-22.** CVE-2026-85102: pre-auth RCE in Security Gateway VPN certificate validation — being hit primarily against Spark (SMB) customers globally; original disclosure was 2026-09-09 but CISA batched it in today. CVE-2026-93616: pre-auth path traversal in the management-server web service that lets an attacker execute a script from an arbitrary path and load an arbitrary Java class — hotfix released today (2026-09-22), with Check Point Research reporting "pinpointed" exploitation. Telco relevance: Check Point runs behind managed-security offerings at MSSPs and inside enterprise-connect / IoT / SIM-management VPN aggregation. [Check Point advisory blog](https://blog.checkpoint.com/security/security-advisory-action-required-active-exploitation-of-cve-2026-85102-and-a-management-pre-authentication-vulnerability-cve-2026-93616) · [The Hacker News](https://thehackernews.com/2026/09/check-point-warns-of-management-server.html) · [SecurityAffairs](https://securityaffairs.com/199549/security/check-point-fixes-a-new-actively-exploited-critical-security-flaw.html) · [SecurityOnline](https://securityonline.info/checkpoint-vpn-vulnerability-cve-2026-85102/) — 2026-09-22 (KEV addition) — CRITICAL

## General high-severity

- **HPE Aruba Analytics & Location Engine (ALE) 5.1.0.0** ships fixes for 10 vulnerabilities, two rated **CVSS 9.8** — unauthenticated remote attackers can gain root or write arbitrary files on ALE servers. ALE is deployed on campus and university networks to map Wi-Fi devices across physical spaces, so compromise gives both control of the appliance and access to a stream of subscriber-adjacent location data. Not yet in KEV. Patch immediately; there is no rated workaround. [SecurityOnline writeup](https://securityonline.info/hpe-ale-vulnerabilities-patch/) — 2026-09-22 — CRITICAL

- **SolarWinds Observability Self-Hosted — CVE-2026-28324 (CVSS 9.8) unauth RCE via insufficient integrity checks + CVE-2026-28325 (CVSS 8.8).** Only "non-default and non-secure" configurations are named as affected, but the vendor's own trust-center wording is unusually terse — worth verifying whether your Observability deployment is actually on the "default" side of the fence before assuming safe. Fix: upgrade to 2026.2.3. [SolarWinds Trust Center](https://www.solarwinds.com/trust-center/security-advisories/cve-2026-28298) (index page — CVE-28324 advisory is the newest entry) · [SecurityOnline](https://securityonline.info/solarwinds-observability-vulnerabilities-fixed/) — 2026-09-22 — HIGH
