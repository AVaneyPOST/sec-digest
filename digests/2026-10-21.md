## Telecom
- **Oracle Communications quarterly CVE batch — Oracle October 2026 CPU, released 2026-10-20.** The pre-release summary confirms 1,283 patches total but does not break out Communications. Pattern across recent quarters makes this directly operationally relevant to a telco: **Oracle Communications was the single largest patch family in both the April 2026 CPU (139 patches, 93 unauthenticated/remote) and the July 2026 CPU (168 patches, 122 unauthenticated/remote)**. Any telco running Session Border Controller, Diameter Signaling Router, Communications Policy Management, Communications Billing & Revenue Management, Unified Session Manager, Communications Convergence, or SD-WAN Edge should pull the Communications risk matrix from Oracle's advisory and prioritize anything scored ≥9 with `AV:N` and `Au:N`. The pre-release said highest CVSS on Database is 8.8 and on APEX is 9.8, but those are different families; the Communications ceiling in prior quarters has repeatedly hit 10.0 on auth-less remote. [[Oracle Critical Patch Update Pre-Release Announcement — October 2026](https://www.oracle.com/security-alerts/cpuoct2026.html)] [[April 2026 Oracle Communications analysis — SecurityArsenal](https://securityarsenal.com/blog/oracle-april-2026-cpu-analysis-and-remediation-of-34-critical-vulnerabilities-in-oracle-communications)] [[July 2026 CPU summary — Tenable](https://www.tenable.com/blog/oracle-july-2026-critical-patch-update-addresses-1235-cves)] — Severity: **CRITICAL** (patch-cycle, telco-adjacent).

- **BeyondTrust Remote Support CVE-2026-102764 — ARMORY CASTLE / UNC5221 / WARP PANDA attribution.** Still live and still the single most telecom-relevant open thread: CVSS 4.0 9.3 authentication bypass + arbitrary file ops on Remote Support appliances; CISA KEV-listed Oct 16; Mandiant explicitly warned to expect broader exploitation attempts. Remote Support appliances are standard tooling inside MSP/MSSP and operator-SOC environments and this chain is a direct identity-pivot route into downstream telco tenants. All Remote Support versions through 26.2.3 affected; self-hosted customers running 24.3.1–26.2.3 must apply BT26-05-RS. [[SOCPrime](https://socprime.com/?p=54734)] [[eSecurity Planet](https://www.esecurityplanet.com/threats/news-beyondtrust-zero-day-china-hackers/)] [[CISA alert](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-urges-patching-critical-vulnerability-beyondtrust-remote-support)] — Severity: **CRITICAL** (CISA KEV).
- **PEERSTITCH on a telecom MSP (Unit 42; CVE-2025-61624 KEV-added 2026-10-16).** Memory-resident ARM64 malware with no on-disk binary, no listening port, no outbound-initiated connection — piggybacks C2 on legitimate `/bin/miglogd` and `/bin/iked` traffic. Initial access via FortiJump; privilege/persistence via FortiOS auto-script path traversal CVE-2025-61624 (patched April 2026, now KEV-listed). Credentials and configs for 500+ downstream customer firewalls exposed. Patching does not evict the implant; memory forensics + credential rotation required. [[SC World – CISA Fortinet/BeyondTrust add](https://scworld.com/brief/cisa-adds-fortinet-and-beyondtrust-vulnerabilities-to-exploited-list)] [[CISA alert](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-adds-two-known-exploited-vulnerabilities-catalog)] — Severity: **HIGH** (telecom-adjacent, nation-state-grade tradecraft).
