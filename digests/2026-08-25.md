## General high-severity

- **CISA adds CVE-2026-21962 (Oracle HTTP Server & WebLogic Server Proxy Plug-in) to KEV.** Improper access control, CVSS 10.0, unauthenticated remote — attackers craft HTTP requests with path traversal and header manipulation to bypass the proxy's front-end and gain the plug-in's access level, chaining to RCE on backend WebLogic. Public PoC since Jan 21, 2026 and SANS ISC saw probing on Jan 28; today's KEV listing formalises the in-the-wild exploitation record and gives US federal agencies a remediation deadline. Fix ships in Oracle's Jan 2026 CPU. — [CISA alert](https://www.cisa.gov/news-events/alerts/2026/08/24/cisa-adds-one-known-exploited-vulnerability-catalog) · [SentinelOne write-up](https://www.sentinelone.com/vulnerability-database/cve-2026-21962/) · Date: **2026-08-24** · **CRITICAL**

- **Check Point Research — 24th August Threat Intelligence Report.** Weekly rollup pulling together several late-week items: Cisco's Aug 19 batch (nine critical CVEs across Crosswork and Secure Workload, six at CVSS 10.0), Citrix NetScaler CVE-2026-19489/19490, GitLab CVE-2026-19478 exploitation, and the Cl0p Windchill/FlexPLM (CVE-2026-12569) extortion campaign now naming 40+ victims. — [Check Point](https://research.checkpoint.com/2026/24th-august-threat-intelligence-report/) · Date: **2026-08-24** · **NOTABLE**

## Worth watching

- **Citrix NetScaler ADC / Gateway — CVE-2026-19490 (CVSS 9.3) authentication bypass.** SAML/Gateway/AAA vserver configurations; on older builds any Gateway or AAA vserver is enough to be exposed. Companion CVE-2026-19489 (CVSS 8.8) is an SIP-ALG memory overflow. Patches: 14.1-73.32, 13.1-63.21 and later. Disclosed Aug 20–21; Citrix urging immediate upgrade. High historical exploitation base rate for this vendor. — [Citrix bulletin](https://support.citrix.com/external/article/CTX696939/netscaler-adc-and-netscaler-gateway-secu.html) · [Help Net Security](https://www.helpnetsecurity.com/2026/08/21/citrix-netscaler-gateway-cve-2026-19490/) · **CRITICAL** (watch for KEV addition)
- **GitLab CVE-2026-19478 (CVSS 9.4) GraphQL code injection, unauthenticated.** Out-of-band patch Aug 17 (CE/EE 19.2.4, 19.1.6, 19.0.8, 18.11.11). watchTowr reports honeypot exploitation began ~Aug 19. Attackers can modify or delete public projects and user data via the `@gl_introduced` directive. Self-hosted instances at risk; GitLab.com already patched. — [The Hacker News](https://thehackernews.com/2026/08/gitlab-cve-2026-19478-comes-under.html) · [SecurityOnline](https://securityonline.info/gitlab-cve-2026-19478-code-injection/) · **CRITICAL**
- **Cl0p PTC Windchill/FlexPLM campaign (CVE-2026-12569).** Deserialization RCE (CVSS 9.8) chained with a pre-auth WSDL info-disclosure. JSP webshells, engineering-data theft. In KEV since June 25. Cl0p has now publicly named 40+ victims (Shell, Philips, Fiserv, Zebra, Mindray, Largan among them) — expect continued weekly additions. — [SecurityWeek](https://www.securityweek.com/cl0p-ransomware-group-names-over-40-victims-of-ptc-windchill-campaign/) · **HIGH** (ongoing)
- **Cisco Aug 19 hardening advisories — Crosswork and Secure Workload.** Nine critical CVEs, six at CVSS 10.0, from internal reviews (no known active exploitation at publish time). Auth/access-control/filesystem weaknesses. Telco-adjacent (Crosswork sits inside carrier NOC/OSS stacks). — [Cisco advisory hub](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-notice-LDquvx5d) · **CRITICAL** (patch cadence)
- **Sandworm UAC-0145 fake-recruiter WireGuard trojan (Ukraine).** CERT-UA disclosed Aug 11, activity since May 2026. Not new news this cycle, but attribution to a GRU subgroup and the trojanised WireGuard build make this relevant to any org employing Ukrainian sysadmins/IT contractors.
