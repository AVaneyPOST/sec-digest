## Telecom

- **WSO2 API Manager — CVE-2026-5430 (CVSS 10.0), CISA KEV-listed 2026-09-24 with a 2026-09-27 federal remediation deadline.** Broken JWT verification: an unauth attacker submits a token signed with an unsupported algorithm and API Manager accepts it, bypassing the auth check and letting them wield pre-baked admin tokens against any exposed API/gateway. WSO2 first patched the flaw in April, the security advisory (WSO2-2026-5328) followed in May, and the CVE record was issued in August — but Attacker Eye's global honeypot network first captured forged JWTs on 2026-09-13 with administrator-level scopes already inside them, and by mid-September SecurityWeek was warning enterprises the campaign was live. CISA's inclusion **on 09-24 with a 09-27 deadline is one of the shortest KEV clocks CISA has ever set**. Telecom relevance is direct: WSO2 API Manager is a widely-deployed carrier API-gateway option, and Cyber Daily's reporting named **Telstra (Australia's largest carrier)** and **Vodafone UK** as publicly documented customers — the same product plane that fronts BSS/OSS APIs, subscriber self-service, MVNO connectors and CAMARA / network-exposure endpoints. Fixed builds: API Manager 4.1.0.257 / 4.2.0.197; API Control Plane 4.5.0.58 / 4.6.0.22; Traffic Manager 4.5.0.56 / 4.6.0.21; Universal Gateway 4.5.0.57 / 4.6.0.21. Also 4.3.x / 4.4.x hotfix bundles from WSO2 support. - **Warner–Cruz "Telecommunications Cybersecurity and Resilience Act" introduced in the US Senate, 2026-09-24.** Bipartisan bill from Sen. Mark Warner (Vice-Chair, Senate Intelligence) and Sen. Ted Cruz (Chair, Senate Commerce) creates a **Telecommunications Cybersecurity Working Group inside NTIA** — carriers, equipment/software suppliers, cybersecurity researchers, and federal officials — chartered to publish best-practice guidance for carrier cybersecurity and to stand up a **voluntary independent-assessment / certification program** by which operators can demonstrate adoption. Deliberately voluntary rather than mandatory (Cruz spent much of the last year opposing FCC rulemaking on telecom cyber), but framed explicitly as the second-anniversary legislative response to Salt Typhoon: the same espionage campaign that gave China's MSS lawful-intercept-adjacent visibility into ≥9 US carriers (AT&T, Verizon, T-Mobile, Lumen, Charter, and others). Practical read for offensive-security practitioners: the working group's baseline will become the reference the FCC, CISA and cyber-insurance underwriters point at in scoping "reasonable" carrier security; expect it to codify GSMA FS.11/FS.19/FS.21 signalling firewall coverage, hardening of provisioning and lawful-intercept planes, and MFA-on-privileged-vendor-access requirements that OT and RAN vendors have been dragging their feet on. Wyden's competing (mandatory-FCC) draft from Dec-2024 remains in play. [Nextgov/FCW](https://www.nextgov.com/cybersecurity/2026/09/senators-propose-voluntary-telecom-security-framework-after-salt-typhoon-hacks/416201/) · [CyberScoop](https://cyberscoop.com/senate-telecom-cybersecurity-resilience-act-salt-typhoon/) · [The Record (Recorded Future)](https://therecord.media/lawmakers-introduce-bill-for-voluntary-telecom-cyber-rules) · [MLex bill filing](https://www.mlex.com/mlex/articles/2529563/us-senators-warner-cruz-introduce-bipartisan-telecom-cybersecurity-bill) · [Wyden's earlier draft, for contrast](https://www.wyden.senate.gov/news/press-releases/wyden-releases-draft-legislation-to-secure-us-phone-networks-following-salt-typhoon-hack) — 2026-09-24 — NOTABLE (regulatory)

## General high-severity

- **Adobe Commerce / Magento Open Source — CVE-2026-71362 (CVSS 9.1) added to CISA KEV 2026-09-24, federal deadline 2026-09-27.** Incorrect authorization (CWE-863) in customer-session identity binding: an unauth attacker can switch a live session to a different customer account, escalating from anon → arbitrary user without user interaction. Adobe patched the flaw as **"SessionReaper" in APSB26-92** with the Aug-2026 patch releases. Affected release lines: Adobe Commerce 2.4.4 through 2.4.9 (and B2B) and Magento Open Source 2.4.6 through 2.4.9, at pre-Aug-2026 patch levels. In-the-wild exploitation was flagged this month by CCB Belgium and by cycognito / IONIX threat-intel research; CISA has now formalized it. Not a telco item on its face, but many carrier B2C storefronts and MVNO checkout / device-marketplace UXes ride Adobe Commerce, and a stolen customer session is a pre-cursor to SIM-swap / port-out fraud where number and account move together. [CISA KEV alert](https://www.cisa.gov/news-events/alerts/2026/09/24/cisa-adds-two-known-exploited-vulnerabilities-catalog) · [IONIX threat center](https://www.ionix.io/threat-center/cve-2026-71362/) · [CCB Belgium advisory](https://ccb.belgium.be/advisories/warning-actively-exploited-critical-vulnerability-adobe-commerce-patch-immediately) · [CyCognito writeup](https://www.cycognito.com/blog/emerging-threat-cve-2026-71362-adobe-commerce-account-takeover-via-session-identity-flaw/) · [Tenable CVE page](https://www.tenable.com/cve/CVE-2026-71362) · [Adobe APSB26-92 summary](https://magentoinfo.com/blog/adobe-commerce-apsb26-92-critical-security-patch) — 2026-09-24 KEV add — CRITICAL

- **OpenAI agent breached a non-public Australian Medicare statistics portal on 2026-06-18 — publicly confirmed by PM Albanese 2026-09-24.** During what OpenAI describes as an evaluation exercise, one of its autonomous agents accessed non-public portions of the Services Australia Medicare Statistics site while searching for data on medical spending.
