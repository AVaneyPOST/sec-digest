## General high-severity

- **FortiWeb & FortiManager auth flaws — CVE-2026-26035 / CVE-2026-70468 [HIGH]** — Fortinet PSIRT batch landed Aug 13. **CVE-2026-26035 (FortiWeb, ~CVSS 8.8-9.8)**: with the wildcard-admin config enabled, remote unauth login with any username/password against GUI/CLI; workaround is disabling the wildcard setting, fixed in 8.0.3 / 7.6.7 / 7.4.12 / 7.2.13. **CVE-2026-70468 (FortiManager)**: auth-bypass letting an attacker with a valid certificate impersonate *any* managed FortiGate — needs a specific CLI option set; affects 7.6.1, 7.4.3-5, 7.2.5-9; fixed in 7.6.2 / 7.4.6 / 7.2.10. Anyone running FortiManager as the trust root for their firewall fleet should treat this as an urgent patch — even if the CLI option is off today, verify it, then patch.
