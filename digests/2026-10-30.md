## General high-severity

- **[CRITICAL] CISA KEV adds CVE-2026-97229 — GitLab CE/EE unauth RCE, CVSSv3.1 10.0 — on 2026-10-29.** Integer overflow in the Onigmo regex compiler reachable from CI/CD config parsing. Pre-auth with just the ability to push a malicious `.gitlab-ci.yml` (a fresh self-service account is enough on default instances). Rapid7 reproduced RCE on the stock official CE image. Fixes: 19.5.1 / 19.4.3 / 19.3.6 / 19.2.9 / 19.1.9 / 19.0.10 / 18.11.13. **Correction to yesterday**: the CVE was carried as CVE-2026-110264; the KEV-listed canonical ID is CVE-2026-97229 — version strings in yesterday's entry are still correct. Any carrier-run self-managed GitLab is a high-value target (CI secrets, source trees, pipeline-driven infra access). Date: 2026-10-29. [Rapid7 ETR](https://www.rapid7.com/blog/post/etr-cve-2026-97229-critical-unauthenticated-remote-code-execution-in-gitlab) · [Rapid7 technical analysis](https://www.rapid7.com/blog/post/ra-gitlab-ci-cd-regex-integer-overflow-technical-analysis-cve-2026-97229) · [Cyber Daily](https://www.cyberdaily.au/security/14302-patch-now-gitlab-publishes-fixes-for-perfect-10-vulnerability-cve-2026-97229). KEV mirror: [dgwhited/kev `kev-update-2026-10-29-195435`](https://github.com/dgwhited/kev/releases/tag/kev-update-2026-10-29-195435) (catalog version 2026.10.29). Severity: **CRITICAL**.

- **[HIGH] CISA KEV adds CVE-2026-76418 — Cisco Secure Firewall ASA / FTD SSL VPN zero-day, actively exploited — on 2026-10-29.** Cisco advisory published 2026-10-28; impact per Cisco is DoS (device reload) only, no RCE or data-theft claim. No workaround; upgrade required. Distinct from the Aug 2026 CVE-2026-20349 ASA/FTD SSL VPN DoS. For a telco, this is operator remote-access and admin-plane VPN termination equipment — a DoS zero-day in an in-wild status means an urgent change-controlled upgrade. Date: 2026-10-28 (advisory) / 2026-10-29 (KEV). [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisco-warns-of-asa-and-ftd-vpn-flaw-exploited-to-crash-devices/) · [eSecurity Planet](https://www.esecurityplanet.com/threats/cisco-warns-of-active-exploitation-of-asa-and-ftd-0-day-vulnerability/) · [Cybersecurity News](https://cybersecuritynews.com/cisco-secure-firewall-0-day-vulnerability-exploited). Severity: **HIGH**.

- **[HIGH] Dream Security: PHP2Shell + Fragnesia chain compromised 25 servers in the wild, including a US-government-affiliated environment (publicised 2026-10-28/29, investigation dated 2026-10-26).** Entry via an exposed firewall-management web interface → PHP2Shell (CVE-2026-109618 / CVE-2026-109619, unauth RCE in PHP SAPI handling) → Fragnesia (CVE-2026-46300, Linux kernel XFRM ESP-in-TCP LPE) → root on 24 perimeter firewalls plus one internal management server. Date: 2026-10-28/29 (coverage window). [Unite.ai writeup](https://www.unite.ai/dream-reports-php2shell-attack-chain-that-compromised-25-servers/). Severity: **HIGH** (critical for anyone whose perimeter stack ends up being the undisclosed vendor).
