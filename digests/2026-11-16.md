## General high-severity

**KEV deadline 2026-11-16 (today): UnrealIRCd CVE-2026-114713 + Check Point CVE-2026-123039** · [HIGH]
Both landed in KEV on 2026-11-13 with unusually short 3-day federal deadlines; today is that deadline.

- **CVE-2026-114713** — UnrealIRCd 6.0.0–6.2.7 server-to-server command injection. Hot-patch and 6.2.7.1 shipped 2026-11-07. Maintainer on oss-sec: "We are seeing bad guys exploiting this issue on the internet right now." Normal users can execute commands with server / IRCOp authority. Workaround: spamfilter-rule filter prior to patch. Rarely on carrier infrastructure, but worth checking any residual legacy chat relays.
- **CVE-2026-123039** — Check Point Multiple Products, DynamicCLI world-writable local socket on Gaia OS → local root. Reportedly exploited against "a couple dozen customers." Both KEV entries carry `forensicTriage: Yes`; `knownRansomwareCampaignUse: Unknown` on both. Check Point gateways sit on some telco perimeter paths (operator-IT DMZ, some S-GW / M2M management segments, support-vendor jump paths). Priority hunt: any Gaia appliance whose shell is reachable by any human admin or support-vendor account; look for unexpected writes to the DynamicCLI socket path and unexpected EUID-0 processes forked from it.
