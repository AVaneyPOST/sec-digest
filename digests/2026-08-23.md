First documented Android-malware campaign with an infection chain purpose-designed for automotive head-units. Kaspersky's Dmitry Kalinin surfaced the activity in June 2026 while monitoring Android threats and traced infections to **TWCore**, the legitimate first-party system-app that DoFun-based Android head units use for telemetry / analytics / OTA updates. Once TWCore is subverted, it drops **JarService** — an interfaceless loader that behaves like a normal Android app but makes no attempt to impersonate a legitimate one, has no launcher icon, no UI — which contacts a C2 to pull further modules. Downstream monetization is a mix of **residential-proxy** (device is enrolled as an exit node in a for-rent proxy pool) and **ad-fraud** (device generates click / impression traffic). Kaspersky attributes with high confidence to **MoYu Group**, previously linked to the **BADBOX** botnet ecosystem — an Android-firmware / IoT-focused Chinese-language crimeware collective. DoFun reports the issues have been fixed. **~30 million vehicles worldwide** run DoFun head-units per the vendor's own numbers.

Telecom-operator relevance:
- **Novel egress channel from cellular subscriber IP ranges.** Modern automotive head-units backhaul through the vehicle's TCU / telematics module, which typically sits on a carrier-provisioned data-only APN. A proxy botnet resident inside that population lets an attacker source traffic from `mobile-carrier-X automotive TCU` IP allocations — clean, geographically distributed, and not currently modelled in most fraud / abuse detectors as a proxy source. Expect operators to see anomalous outbound patterns (credential stuffing, ad-fraud clicks, scraping) attributable to automotive-TCU-labelled subscriber IPs.
- **Fleet-scale abuse of an auto-updater primitive.** The infection primitive is a legitimate first-party updater (TWCore); the same pattern is broadly reusable against any operator-managed device population that ships with vendor-controlled OTA — CPE / femtocell / small-cell / eSIM-provisioned IoT modules. Operators running IoT-connectivity platforms (Cisco Jasper, Ericsson IoT Accelerator, Vodafone GDSP, Deutsche Telekom nuSIM) should re-check the trust boundary on any first-party updater component that has network reach to the module OS.
- **BADBOX-adjacency signal.** MoYu / BADBOX historically pre-seeded Android firmware images with malicious payloads at the manufacturing stage (Android TV boxes, tablets, projector heads); the DoFun campaign is the first automotive-head-unit pivot. If the pre-seeding stays true to that TTP, some of the compromised device population may have been backdoored before it left the factory — patches to TWCore won't fix that, and re-flash may be needed.
