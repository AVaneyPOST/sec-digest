## General high-severity

- **CVE-2026-104286 — Fortinet FortiMail management-interface arbitrary file write (CVSS 9.8), zero-day exploited in the wild, Fortinet FG-IR-26-175 published 2026-10-01, KEV-listed 2026-10-01 with 2026-10-04 federal remediation deadline. This is the day's single new in-window critical item.** Unauthenticated, remote path traversal (CWE-22) combined with improper NULL-byte handling (CWE-158) in the management interface allows an attacker to write arbitrary files on the appliance via crafted HTTP / HTTPS requests — the practical outcome is `.so` preload, webshell drop and configuration tampering, all pre-auth, all over the admin plane. **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. **Fixed:** 8.0.2, 7.6.7, 7.4.9. **Interim workaround** (Fortinet): disable the IBE (Identity-Based Encryption) feature and restrict management-interface access to trusted networks (`trusthost` / dedicated OOB only). **Vendor-published IOCs:** dropped files `/data/lib/liblog.so`, `/data/bin/webconsole`, `/data/bin/mailservice`, `/data/etc/ld.so.preload`; tampered artifacts `/bin/smit`, `/data/etc/httpd.conf`, `/data/migadmin.tar.gz`. Telecom-practitioner relevance: FortiMail is a common choice for carrier email relays, enterprise mail-gateway services sold to business customers, dealer / channel inboxes, NOC help-desk / ticketing-forwarders and MVNO back-office mail; any such appliance exposing its admin plane outside OOB is in scope today, and any FCEB tenant on the affected trains has until 2026-10-04 to patch. Hunt scope: match the file-path IOCs against appliance file-system snapshots, pull `httpd.conf` / `ld.so.preload` deltas, review admin-plane HTTP(S) access logs for anomalous unauthenticated path components around and before 2026-10-01. [Fortinet PSIRT (FG-IR-26-175, FortiGuard advisory feed)](https://fortiguard.fortinet.com/psirt) · [BleepingComputer — FortiMail zero-day coverage](https://www.bleepingcomputer.com/news/security/fortinet-warns-of-critical-fortimail-flaw-exploited-in-zero-day-attacks/) · [SecurityOnline — FortiMail CVE-2026-104286](https://securityonline.info/fortimail-vulnerability-cve-2026-104286/) · [Suped — CISA flags active exploitation](https://www.suped.com/blog/cisa-flags-active-exploitation-of-fortimail-cve-2026-104286) · [GovInfoSecurity — Attackers target zero-day in Fortinet security software](https://www.govinfosecurity.com/attackers-target-zero-day-flaw-in-fortinet-security-software-a-31344) · [runZero — FortiMail asset-inventory guidance](https://www.runzero.com/blog/fortinet-fortimail/) — 2026-10-01 — **CRITICAL (KEV, zero-day)**
