## Worth watching

Operator relevance is indirect but real: any carrier dev team using Zeabur for staging/sandbox should rotate anything that was stored in a Zeabur env var — including LLM API keys, which the earlier (Aug) breach is reported to have let attackers drain. [[BleepingComputer — Zeabur shutting down](https://www.bleepingcomputer.com/news/security/zeabur-shutting-down-after-second-security-breach-in-two-months/)] [[Zeabur Oct 2026 incident post](https://zeabur.com/es-ES/blogs/october-2026-security-incident)] [[AlphaMatch — Zeabur env var leak](https://www.alphamatch.ai/blog/zeabur-env-variable-leak-api-keys-2026)].
