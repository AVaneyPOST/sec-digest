## Telecom

- **House Select Committee on China releases Salt Typhoon infrastructure report.** [NOTABLE]
  Committee found that despite FCC restrictions, China Mobile, China Telecom, and China Unicom "quietly obtained or retained hardware, interconnection agreements, and data center footholds" inside US networks. Between 22–25 September 2024, China Mobile International's network appeared 192 times in active BGP paths to 58 IP groups CISA attributes to Salt Typhoon C2. Analysis also flags ~109,000 unauthorized US-prefix origination events attributed to Chinese/HK-linked networks between Jan 2018 and May 2025. Committee does not directly attribute Salt Typhoon activity to China Mobile employees. Why it matters for offensive telco security: even a "prohibited" foreign carrier can remain adjacent to the routing plane via colocation and interconnect leftovers — worth adding to the RAT model as a pivot / mass-surveillance surface.

## General high-severity

- **CVE-2026-20200 — Cisco IMC command execution as root, public PoC live.** [CRITICAL]
  CVSS 9.8. Authenticated-low-priv attacker on the IMC web UI reaches OS-level root on the underlying UCS C-series / S-series BMC via insufficient input validation. Researcher "Peil" published PoC "CIMCown" on GitHub following the 2026-08-05 advisory batch. Compromise gives BIOS / SecureBoot influence over every OS booted on the box — this is a lateral-movement / persistence goldmine for anyone running Cisco UCS underneath their virtualization or 5G CNF workloads. No workaround; upgrade IMC and firewall the IMC segment.
  [Help Net Security (2026-08-06)](https://www.helpnetsecurity.com/2026/08/06/cisco-imc-cve-2026-20200-public-poc-exploit/) · [News4Hackers](https://www.news4hackers.com/critical-cisco-imc-vulnerability-allows-root-access-poc-available-cve-2026-20200) · [Cisco advance notification](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-notice-L4XfJg8S) · Disclosed 2026-08-05; PoC public 2026-08-06

- **CVE-2026-18577 — N-central takeover playbook confirmed; Cloudflared tunnel persistence.** [CRITICAL]
  Rapid7 / N-able / third-party IR post-mortems now describe the full chain: unauth admin over N-central → Take Control into managed endpoints → drop `svchost.exe` in a user's Documents folder → register it as service `Cloudflared` for out-of-band C2 that survives the N-central fix. Hotfix build 2026.3.1.7 closes the auth bypass but does NOT clean the endpoint implants. Finland's NCSC-FI published an advisory 2026-08-02 stating every version prior to the hotfix is vulnerable. If you are an MSP still on 2026.3.x pre-HF1, assume tenant compromise — sweep for the two IoCs.
  [The Hacker News (Aug 6)](https://thehackernews.com/2026/08/n-able-says-attackers-take-over-n.html) · [Rapid7 ETR](https://www.rapid7.com/blog/post/etr-cve-2026-18577-n-able-n-central-authentication-bypass-exploited-in-the-wild/) · [N-able status: 2026.3 HF1](https://status.n-able.com/2026/08/02/n-central-2026-3-hotfix-1-mitigation-for-cve-2026-18577/) · [Huntress IR write-up](https://www.huntress.com/blog/n-able-vulnerability-exploitation) · Ongoing exploitation reporting through 2026-08-06

- **CVE-2026-63077 — JetBrains TeamCity unauth RCE via agent-polling deserialization; KEV.** [CRITICAL]
  CVSS 9.8, CWE-502. Crafted payload to the agent-polling endpoint hits an untrusted deserialization gadget chain; attacker executes OS commands as the TeamCity server user. Any unauthenticated HTTP(S) reach is enough. Fixed in 2025.11.7 and 2026.1.3; older LTS lines get a security patch plugin. CISA added it 2026-08-05, federal deadline 2026-08-08. Given TeamCity's role as a CI credential vault, exploitation collapses your whole build-and-sign pipeline.
  [Rapid7 ETR](https://www.rapid7.com/blog/post/etr-cve-2026-63077-critical-unauthenticated-remote-code-execution-in-jetbrains-teamcity/) · [SentinelOne CVE page](https://www.sentinelone.com/vulnerability-database/cve-2026-63077/) · [JetBrains advisory (2026-07-27)](https://blog.jetbrains.com/teamcity/2026/07/cve-2026-63077/) · [The Hacker News (Aug 6)](https://thehackernews.com/2026/08/cisa-flags-teamcity-cve-2026-63077-rce.html) · [Security Affairs](https://securityaffairs.com/196725/security/u-s-cisa-adds-a-jetbrains-teamcity-flaw-to-its-known-exploited-vulnerabilities-catalog.html) · KEV: 2026-08-05

## Worth watching

- **CVE-2026-64531 "OVSwrap" — 13-year-old Linux kernel LPE via Open vSwitch datapath.** Integer wraparound on a 16-bit length field in an internally generated Netlink action stream produces a deterministic memory-corruption primitive → unprivileged local user to root on default-configured Debian ≥12, Ubuntu ≥22.04, and RHEL variants. `openvswitch.ko` auto-loads on demand so the module doesn't need to be actively in use to be exploitable. Disclosed by Asim Manizada 2026-07-28, upstream fix already in stable kernels 2026-07-24. Public exploit reported to cover ~800 kernel builds — expect containerized workloads to be next. [SecurityAffairs](https://securityaffairs.com/196657/hacking/ovswrap-13-year-old-linux-kernel-flaw-lets-local-users-become-root.html) · [GBHackers](https://gbhackers.com/ovswrap-open-vswitch-flaw/) · [CloudLinux advisory](https://blog.cloudlinux.com/ovswrap-cve-2026-64531-mitigation/)

- **Microsoft Patch Tuesday drops 2026-08-11/12 with the embargoed SharePoint chain.** Aug drop is expected to close the RCE that pairs with July's CVE-2026-55040 JWT auth bypass in SharePoint Server (Subscription / 2019 / 2016). Storm-2603 (Warlock ransomware) has been hunting on-prem SharePoint since mid-2025 — any Internet-reachable farm is on the clock. [ByteIota preview](https://byteiota.com/microsoft-august-patch-tuesday-2026-sharepoint-rce/) · [Secure in Seconds](https://www.secureinseconds.com/blog/2026-07-27-patch-tuesday-august2026-secureinseconds)

- **`keyv` npm supply-chain worm (2026-08-04) — Shai-Hulud variant with IDE-hook payloads.** Attacker took over maintainer's GitHub, pushed poisoned versions of `keyv`, `cacheable`, and eight sibling packages (aggregate ~2B monthly downloads), riding valid OIDC/SLSA provenance through the legit GitHub Actions release workflow. Payload committed VS Code and Claude Code hook files into checkouts, so a bare `git clone` (no `npm install`) can still detonate. Total spread: 2,234 poisoned versions across 444 package names in ~30 minutes. Continuing IR through this week — audit `npm ls keyv` on every CI runner and every developer laptop. [Snyk](https://snyk.io/blog/inside-keyv-npm-compromise-preinstall-malware-trusted-provenance-ide-hooks/) · [Datadog Security Labs](https://securitylabs.datadoghq.com/articles/npm-worm-compromises-popular-npm-packages/) · [Wiz](https://www.wiz.io/blog/keyv-and-cacheable-npm-supply-chain-attack) · [Aikido](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack)

Coldcard halted shipments and destroyed remaining stock. Not a telco/enterprise item, but a canonical example of a supply-chain / firmware-trust failure worth citing when hardening HSM procurement.
