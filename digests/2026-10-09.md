## Telecom

- **CISA KEV batch 2026-10-08 — five historical CVEs added, pattern consistent with a Flax Typhoon / Integrity Technology Group infrastructure sweep.** All five land with a 2026-10-11 BOD-26-04 remediation deadline (Sunday → effectively 2026-10-13 operational close), and ransomware-use is tagged "unknown" across the batch. **Vendor / product breakdown and carrier footprint:**
  - **CVE-2015-5477** — ISC BIND 9.x prior to 9.9.7-P2 and 9.10.x prior to 9.10.2-P3, denial-of-service via remote TKEY queries that trigger a REQUIRE-assertion failure and daemon exit (CWE-617 / CVSS 7.5). The TKEY-query DoS is a one-packet kill: no authentication, no state. Public exploits have existed since July 2015; the vulnerability has been in the F5 BIG-IP bug tracker (K16909) and Red Hat Security Advisory RHSA-2016:0078 since 2015. **Carrier footprint:** every operator runs BIND somewhere — authoritative DNS for subscriber-facing portals and OAM-plane name resolution, caching resolver for subscriber-DNS and VoLTE/VoNR IMS lookups, and sometimes signaling-adjacent (ENUM / sip-naptr). A 9.9.7-P1 or earlier instance anywhere on the operator estate is a one-packet-DoS target.
  - **CVE-2016-3081** — Apache Struts 2 (versions 2.3.19 through 2.3.28, with Dynamic Method Invocation enabled), remote code execution via crafted `method:` prefix in a chained OGNL expression (CVSS 8.1, 23 public PoCs on GitHub as of KEV listing). Unauthenticated. **Fix:** upgrade to 2.3.28.1 or later and disable DMI. **Carrier footprint:** Struts 2 is still widely embedded in telecom BSS / OSS portals, dealer provisioning web interfaces, legacy charging / billing admin UIs, and content-delivery operator back-office. Any CPE-management portal, dealer channel app or legacy MVNE control panel running Struts 2.3.28 or earlier is in-scope.
  - **CVE-2021-3199** — ONLYOFFICE Document Server 5.6.2, Critical (CVSS 9.8). Published 2021-01-26. ONLYOFFICE Document Server is a common collaborative-editing stack used in enterprise document-sharing deployments (Nextcloud and ownCloud integrations in particular). **Carrier footprint:** carrier IT estates often run Nextcloud or ownCloud for internal collaboration, dealer-portal document attachments, lawful-intercept paperwork retention, and contractor collaboration spaces. ONLYOFFICE 5.6.x shipped on these integrations in 2020-2021; any instance still on 5.6.x is a one-step pivot into the broader collaboration-platform data.
  - **CVE-2015-3306** — ProFTPD 1.3.5 (and earlier), mod_copy module, unauthenticated remote arbitrary file read / write via `SITE CPFR` and `SITE CPTO` commands, chainable into code execution if a writable web directory exists. CVSS 10.0, EPSS 93.68% (100th percentile), six public Exploit-DB entries including a Metasploit module. **Fix:** upgrade to 1.3.5e or disable mod_copy. **Carrier footprint:** ProFTPD is the standard FTP daemon on many operator OSS fileservers (CDR archival, provisioning-file drop, lawful-intercept intermediate storage, NMS staging), on embedded SOHO router and NAS firmware (common Flax Typhoon device targets), and in a long tail of appliance / vendor OEM shipping stacks. An unpatched 1.3.5 anywhere in subscriber CPE, operator-managed-router, or OSS staging is a one-packet file-write primitive.
  - **CVE-2023-22894** — Strapi admin panel, cleartext storage of sensitive information (CWE-312), lets a user with admin-panel access read sensitive user details through the query filter. The CISA entry flags the product as potentially end-of-life / end-of-service and recommends discontinuing use or moving to a supported version. **Forensic triage is required under BOD 26-04 for this one.** **Carrier footprint:** Strapi is a popular open-source Node.js headless-CMS backing custom MVNO web portals, dealer-channel content sites, and operator-side developer portals.
  - **Flax Typhoon alignment.** Flax Typhoon's herd runs ~260,000+ compromised IoT / SOHO / web-content infrastructure devices (September 2024 FBI takedown figure); the September-2024 Five Eyes joint advisory catalogued 66 actively-exploited CVEs on the botnet, of which 27 were already in KEV at the time of that advisory. Today's five fit the remaining-39 shape — all five target end-of-life software families typical of the device set Flax Typhoon runs on.
