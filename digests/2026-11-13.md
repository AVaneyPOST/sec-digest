## Telecom

**KEV deadline cliff — Barracuda ESG + Ivanti Connect Secure both due today 2026-11-13** · [CRITICAL]
Federal-agency remediation deadline reached in-window for two telecom-adjacent items. **Barracuda ESG pre-auth root chain CVE-2026-116606 (authentication bypass that lets attackers restore a crafted backup and modify global configuration) + CVE-2026-111560 (OS command injection via crafted timezone value, executes as root)** — Barracuda confirmed exploitation against "a small number of organizations" at disclosure; ESG is deployed at many Tier-2 operators and MVNOs for carrier-grade email filtering, which makes this a plausible entry-vector into operator back-office stacks even when customer-plane signalling is isolated. Fixed firmware: ESG 9.4.0.030 (BNSF-40425/40430); related patches ship for Load Balancer ADC, Message Archiver, WAF Control Center. **Ivanti Connect Secure CVE-2026-118527** — predictable-identifiers flaw that lets an authenticated attacker upload attacker-controlled file content to a known location on disk; chains with CVE-2026-104935 and CVE-2026-111357 to reach root, attributed to UTA0576. Fixed in 25.1.1.3 / 25.1.3.1 / 22.8R2.6. Operator action: audit any Barracuda ESG-fronted mail paths for backup-restore endpoints still reachable without authentication, and treat any ICS gateway terminating VPN or operator-remote-access that is still on < 25.1.1.3 as compromised-until-proven-otherwise.
