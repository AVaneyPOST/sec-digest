- **CVE-2026-96274 — Baicells Nova 430H LTE TDD eNodeB malformed-uplink flaw (CVSS 8.3), populated inside the window.** "An unauthenticated device within radio range can send a malformed uplink message during connection setup." Pre-attach RAN-layer surface — an attacker with a software-defined-radio stack inside the cell footprint can abuse a corner-case uplink parser without needing valid subscriber credentials. The Nova 430 line is a two-carrier outdoor eNB often rebadged by regional operators for private-LTE, fixed-wireless-access and rural / MVNO coverage; the earlier Baicells Nova 2xx cluster already had an RCE track record (CVE-2023-24508 pre-login command injection, hardcoded SSH credentials in RTS/RTD 3.7.11.3 firmware). Practitioner view: inventory any Baicells rebadge in the FWA / MVNO fleet, pull current firmware level against the vendor's RTS/RTD release train, and treat exposed OAM / NMS interfaces as pre-owned until patched. The RAN-layer blast radius is per-cell rather than estate-wide, but a well-placed denial-of-service against a single rural tower is a credible operator-care incident.
