## Telecom
No dedicated telecom-protocol disclosure landed inside the 24h window. However, the **Cisco Secure FMC CVE-2026-20079** item under "General high-severity" below is directly relevant to telco offensive/defensive security: FMC is the management plane for the ASA/FTD estate widely deployed in ISP, MSP and telco enterprise-IT perimeters, and the observed post-exploitation activity (web shells, proxy tooling, credential theft, reverse shells) is the same living-off-the-perimeter TTP mix Salt Typhoon has used against telecom edges. Telco SOCs should treat unpatched internet-reachable FMC instances as compromised until proven otherwise.

## General high-severity

**CISA KEV additions — 2026-09-09 (four)** — CVE-2025-25249 (Fortinet FortiOS/FortiSwitchManager CAPWAP heap buffer overflow), CVE-2026-19490 (Citrix NetScaler Gateway/AAA auth bypass via alternate path), CVE-2026-20079 (Cisco Secure Firewall Management Center auth bypass, root RCE), CVE-2026-87491 (Google Chromium V8 out-of-bounds write). Federal remediation deadlines apply. [The Hacker News round-up](https://thehackernews.com/2026/09/cisa-adds-seven-exploited-flaws-as.html), CISA alert page (URL blocked from fetch here, retained for readers): `https://www.cisa.gov/news-events/alerts/2026/09/09/cisa-adds-four-known-exploited-vulnerabilities-catalog`. Date: 2026-09-09. **CRITICAL**.

**Cisco Secure Firewall Management Center — CVE-2026-20079, CVSS 10.0, unauth root RCE** — Auth bypass in the FMC web UI: a boot-time process creates a partial `csm_processes` session in the `sfsnort.sessions` DB; if no user authenticates first, the session persists and can be escalated by an unauthenticated attacker sending crafted HTTP requests, yielding root on the underlying OS. Companion issue CVE-2026-20131 (same product, chainable). Cisco confirmed active exploitation; Talos attributes activity to state-sponsored clusters UAT-12197 and UAT-11823 and ransomware operator UAT-11988. Observed post-ex: web shells, JAR-based command executors, Netcat reverse shells, proxy tooling, credential exfiltration. No workarounds — patch to the current Cisco-listed fixed release. [Talos on ongoing exploitation](https://blog.talosintelligence.com/fmc-ongoing-exploitation/), [Horizon3 analysis](https://horizon3.ai/attack-research/vulnerabilities/cve-2026-20079/), [VulnCheck analysis](https://www.vulncheck.com/blog/cisco-fmc-auth-bypass-cve-2026-20079), [CyCognito](https://www.cycognito.com/blog/emerging-threat-cisco-secure-firewall-management-center-root-compromise-cve-2026-20079-cve-2026-20131/). Date added to KEV: 2026-09-09. **CRITICAL**.

**Google Chrome — CVE-2026-87491, V8 out-of-bounds write, exploited in the wild** — Seventh Chrome 0-day of the year. Crafted HTML page triggers OOB write in V8, enabling code execution inside the renderer sandbox; Google flags an exploit exists in the wild but withholds attribution and targeting. Fixed in Chrome 153.0.8010.36/.37 (Windows/macOS) and 153.0.8010.36 (Linux), Stable Channel released 2026-09-08. Reported by Jihyeon Jeong (Compsec Lab, Seoul National University) 2026-08-06. Added to KEV 2026-09-09. [SecurityWeek](https://www.securityweek.com/chrome-153-patches-seventh-zero-day-of-2026/amp/), [Help Net Security](https://www.helpnetsecurity.com/2026/09/09/google-chrome-cve-2026-87491-zero-day-flaw/), [Security Affairs](https://securityaffairs.com/198757/security/google-fixes-the-seventh-actively-exploited-chrome-zero-day-of-2026.html). Date KEV: 2026-09-09. **HIGH**.

**Fortinet FortiOS / FortiSwitchManager — CVE-2025-25249, CAPWAP heap overflow, CVSS 9.8** — Unauth RCE via crafted CAPWAP packets to UDP/5246 in the `cw_acd` daemon. Exploitation traced to at least July 2026, still ongoing; SOCRadar reports campaigns against ~30k FortiGate IPs and 178 confirmed PivotC2 RAT infections (US the largest concentration). Affected: FortiOS 6.4/7.0/7.2/7.4/7.6 branches through the noted revisions; FortiSwitchManager 7.0.x/7.2.x. Added to KEV 2026-09-09 — a >12-month-old CVE now formally hot. [SOCRadar on PivotC2](https://socradar.io/blog/cve-2025-25249-pivotc2-fortigate-rat/), [Cyberpress](https://cyberpress.org/critical-fortigate-flaw-exploited/), [Kudelski research](https://kudelskisecurity.com/research/heap-based-buffer-overflow-in-fortinet-products). Date KEV: 2026-09-09. **CRITICAL**.

**Citrix NetScaler Gateway/AAA — CVE-2026-19490, CVSS 9.3, auth bypass via alternate path (CWE-288)** — Unauth attacker reaches an alternate auth path that misses the controls the deployment expects, on appliances configured as Gateway or AAA vservers — i.e., edge SSL VPN. Patched by Citrix 2026-08-19; PoC public early September; Previdian and others observed exploitation attempts from 2026-09-03; formally KEV'd 2026-09-09. Date KEV: 2026-09-09. **CRITICAL**.

**Ivanti — September 2026 security update** — Advisories for Ivanti Neurons for ITSM, Endpoint Manager Mobile (EPMM), and Sentry. No public confirmation of in-the-wild exploitation of these specific CVEs at time of writing, but Ivanti's recent history (EPMM/Sentry chains have been abused within days of disclosure) warrants same-week patching for internet-reachable instances.
