# Security digest — 2026-09-09

Window: 2026-09-08 04:06 UTC → 2026-09-09 04:06 UTC.

## TL;DR
- **Big patch day.** Microsoft ships its largest Patch Tuesday ever (973 CVEs, ~20 wormable) with two exploited zero-days (CVE-2026-81963 Windows Update Stack EoP, CVE-2026-85880 Windows ALPC heap overflow). Patch domain controllers and DNS/DHCP servers first.
- **SAP OVERPASS (CVE-2026-44756, CVSS 10).** Pre-auth memory corruption in SAP Kernel Extended Passport Processing, reachable via ICM. ~10k internet-facing SAP systems potentially exposed.
- **CISA KEV +4 today.** Adobe Commerce StyleSmuggler (CVE-2026-75650), N-able N-central pre-auth RCE (CVE-2026-86218), plus the two Windows zero-days above — all confirmed exploited.
- **Adobe Commerce/Magento StyleSmuggler.** CVE-2026-75650 (CVSS 10) exploited in the wild to drop a Rust backdoor and a PHP web shell; the C2 masquerades as an NTP host. Hotfix out (VULN-39341 / APSB26-146).
- **Telecom-specific: quiet day.** No new SS7/Diameter/GTP/5G disclosures, no vendor PSIRT drops from Cisco/Ericsson/Nokia/Mavenir/Oracle Comms, no fresh operator breach in-window. The MikroTik "MikroTrick" chain and MBT Telecom incident carry over — see "Worth watching".

## General high-severity

**Microsoft September 2026 Patch Tuesday — 973 CVEs, 2 exploited zero-days, ~20 wormable RCEs** — Record-size release. Two zero-days already exploited: CVE-2026-81963 (Windows Update Stack, EoP) and CVE-2026-85880 (Advanced Local Procedure Call, heap-based buffer overflow) — both added to CISA KEV the same day. Wormable RCEs span DNS, DHCP, RRAS, MSMQ, Failover Cluster, Netlogon, AD DS, SSTP, NFS, SMB Client, IP Helper, ICS and Reliable Multicast. Also notable: CVE-2026-55007 (Exchange RCE), CVE-2026-69465 (SharePoint RCE), CVE-2026-69525 (Remote Desktop Services RCE, CVSS 9.8 use-after-free), CVE-2026-65669 (SQL Server EoP), CVE-2026-80097 (Authenticator EoP). [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-september-2026-patch-tuesday-fixes-966-flaws-2-zero-days/), [Talos](https://blog.talosintelligence.com/microsoft-patch-tuesday-for-september-2026/), [ZDI review](https://www.zerodayinitiative.com/blog/2026/9/8/the-september-2026-security-update-review). Date: 2026-09-08. **CRITICAL**.

**SAP OVERPASS — CVE-2026-44756, CVSS 10, SAP Kernel Extended Passport Processing** — Buffer overflow in the Extended Passport Protocol library reachable through the Internet Communication Manager. Unauth attacker gains arbitrary command execution as the SAP process, i.e. full compromise of the SAP host and business data. Affects KERNEL 7.22, 7.53, 7.54, 7.77, 7.89, 7.93, 8.04, 9.16–9.20. Also patched today: CVE-2026-58240 "S4GET" (CVSS 9.8) — missing auth check in NetWeaver Message Server allowing full cluster access. [BleepingComputer](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-overpass-kernel-vulnerability/), [SecurityWeek](https://www.securityweek.com/sap-patches-critical-extended-passport-processing-vulnerability/), [Onapsis](https://onapsis.com/blog/sap-security-patch-day-september-2026/). Date: 2026-09-08 (SAP Patch Day). **CRITICAL**.

**Adobe Commerce / Magento StyleSmuggler — CVE-2026-75650, CVSS 10** — Unauthenticated PHP template injection via `styles` properties, triggered when Magento renders its "Payment Transaction Failed Reminder" email. In-the-wild exploitation observed from 2026-09-04 (per Sansec); Adobe published hotfix VULN-39341 / APSB26-146 on 2026-09-07 and CISA added it to KEV on 2026-09-08. Payloads seen: Rust-based Linux backdoor with C2 disguised as an NTP server, and a PHP dropper installing a web shell. Affects Magento / Adobe Commerce 2.4.4–2.4.9 — including hosts that had all prior patches applied. [Sansec StyleSmuggler](https://sansec.io/research/stylesmuggler-0day), [Adobe APSB26-146](https://helpx.adobe.com/security/products/magento/apsb26-146.html), [The Hacker News](https://thehackernews.com/2026/09/adobe-patches-magento-zero-day.html). Date: 2026-09-07/08. **CRITICAL**.

**N-able N-central — CVE-2026-86218, CVSS 10, pre-auth RCE (static code injection, CWE-96)** — Fourth N-central hotfix in five weeks; patch shipped 2026-09-06 as 2026.3 Hotfix 4, CISA added it to KEV on 2026-09-08. Huntress reports exploitation attempts in customer environments; N-able's own incident notice says exploitation has been observed in the wild despite mixed messaging. High blast radius for MSPs. [The Hacker News](https://thehackernews.com/2026/09/n-able-issues-fourth-n-central-hotfix.html), [SecurityOnline](https://securityonline.info/adobe-commerce-cve-2026-75650-stylesmuggler/) (Huntress refs). Date: added to KEV 2026-09-08. **CRITICAL**.

**CISA KEV additions — 2026-09-08 (four)** — CVE-2026-75650 (Adobe Commerce template injection), CVE-2026-81963 (Windows link-following / Update Stack EoP), CVE-2026-85880 (Windows heap-based buffer overflow, ALPC), CVE-2026-86218 (N-able N-central static code injection). Federal remediation deadlines apply. [CISA alert](https://www.cisa.gov/news-events/alerts/2026/09/08/cisa-adds-four-known-exploited-vulnerabilities-catalog). Date: 2026-09-08. **CRITICAL**.

## Worth watching

- **MikroTrick — CVE-2026-67276 (SSH pubkey auth bypass, CVSS 9.2) + CVE-2026-86060 (privesc via crafted username, CVSS 9.2)** — Patched by MikroTik on 2026-09-03; CERT Polska disclosed 2026-09-05. Chain gives unauth admin on any RouterOS box with SSH reachable. In-the-wild exploitation from at least 2026-09-02 creating an "ops" account. Not new in this window but still the most impactful edge-router bug of the week — expect botnet operators to pivot to it once patch uptake stalls. Widespread footprint in small carriers, WISPs, enterprise WAN edges. [Help Net Security](https://www.helpnetsecurity.com/2026/09/07/mikrotik-routeros-ssh-vulnerabilities-exploited/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-new-mikrotik-routeros-flaws-to-hijack-routers/). **HIGH**.
- **MBT Telecom (Myanmar) — DYSPHOR1A ransomware claim** — Group claims a full DB dump with 209,970 user records (PII, passwords, device info); disclosure was 2026-09-04. MBT hasn't confirmed. Watch for release-vs-negotiation move. [Ransomware.live](https://www.ransomware.live/id/TUJUIFRlbGVjb21ARFlTUEhPUjFB), [malware.news](https://malware.news/t/dysphor1a-strikes-myanmar-s-mbt-telecom/125360). **NOTABLE**.
- **5G N32 / SEPP roaming** — No new disclosure in-window, but recurring research on TLS 1.3 mode trade-offs (PFS vs replay), and volumetric signalling abuse remaining unaddressed. Worth tracking as 5G SA rollouts widen the roaming trust perimeter. [P1 Security overview](https://www.p1sec.com/blog/sepp-security-in-5g-roaming-how-the-security-edge-protection-proxy-protects-inter-operator-trust).
- **eSIM / Kigen eUICC** — Security Explorations research (2025 disclosure, still under partial embargo) — Java Card type confusion enabling profile cloning and OPc/AMF extraction on GSMA-certified chips. No new drop today; watch for follow-on when embargo lifts. [Security Explorations](https://security-explorations.com/esim-security.html).
