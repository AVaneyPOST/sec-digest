## General high-severity

**CISA KEV — 4 additions (2026-08-18): Windows IKEv2, SharePoint JWT bypass, vCenter root-RCE, macOS Screen Sharing** — [CISA alert (2026-08-18)](https://www.cisa.gov/news-events/alerts/2026/08/18/cisa-adds-four-known-exploited-vulnerabilities-catalog), [ZDI — CVE-2026-33824 Windows IKEv2 RCE](https://www.zerodayinitiative.com/blog/2026/4/22/cve-2026-33824-remote-code-execution-in-windows-ikev2), [SecurityWeek — SharePoint exploited after PoC](https://www.securityweek.com/sharepoint-vulnerability-exploited-shortly-after-poc-release/), [Infosecurity Magazine — vCenter CVE-2026-59310 exploited](https://www.infosecurity-magazine.com/news/vcenter-cve-2026-59310-exploited/), [SecurityWeek — macOS Screen Sharing under active attack](https://www.securityweek.com/recent-macos-screen-sharing-vulnerability-exploited-in-attacks/) — 2026-08-18 — **CRITICAL**
Four separate active-exploitation confirmations in one day.
- **CVE-2026-33824 — Windows IKE Extension double-free, CVSS 9.8.** Unauthenticated RCE via crafted UDP to 500/4500 (IKE / NAT-T). Nearly all supported Windows client and Server SKUs. Microsoft patched in April 2026 CPU; now confirmed ITW.
- **CVE-2026-55040 — SharePoint on-prem JWT auth bypass, CVSS 9.1.** Remote unauth attacker forges JWTs and impersonates any user (incl. admin) by knowing SID/UPN; **Rapid7 has already publicly chained it with a second still-unpatched bug for full RCE** on on-prem SharePoint 2016 / 2019 / SE. Exploitation surged after PoC release.
- **CVE-2026-59310 — VMware vCenter Server Appliance Syslog path traversal → root RCE, CVSS 9.8.** Independent telemetry counts ~**361 victim IPs across 47 countries**, suspected Chinese-speaking actor dropping reverse_ssh implants, cron-job foothold, ESXi ransomware follow-on observed. Broadcom advisory was 2026-07-29 — the exploitation is what makes today's KEV entry.
- **CVE-2026-65400 — macOS Screen Sharing improper auth.** Apple/NVD scored **7.1**, CISA rescored **9.8** on ITW abuse; NCSC-NL sees full root + Monero miners on internet-exposed Macs. Fixed in **macOS Tahoe 26.6.1, Sequoia 15.7.9, Sonoma 14.8.9**. Anyone exposing Screen Sharing / VNC (port 5900) to the internet needs to close it now.

BOD 26-04 remediation dates on all four; federal deadlines short.

**GitLab CVE-2026-19478 — CVSS 9.4, unauthenticated GraphQL directive lets attacker modify/delete public projects & user data** — [The Hacker News](https://thehackernews.com/2026/08/critical-gitlab-graphql-flaw-could-let.html), [Help Net Security](https://www.helpnetsecurity.com/2026/08/18/gitlab-critical-code-injection-flaw-cve-2026-19478/) — patch 2026-08-17, coverage wave 2026-08-18 — **HIGH**
Third GraphQL flaw of the year in GitLab. Unauth remote code-injection primitive delivered via a malicious GraphQL directive — enough to modify or delete public projects and user data on self-managed GitLab. Patched in **19.2.4 / 19.1.6 / 19.0.8 / 18.11.11**. **No confirmed ITW exploitation yet**, but GitLab is a repeat GraphQL target and PoCs historically appear within days. Any internet-exposed self-managed instance should be patched today; SaaS gitlab.com already patched.
